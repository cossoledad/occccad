# CAD 核心主线

当前重点：独立 Part 在实体历史步骤后补建草图，再在该草图后创建同 Body、单方向 FINITE 的 LINEAR_EXTRUDE ADD/REMOVE。全局插入边界与实际实体来源阶段分离，沿原逐次草图命令、生成器预览确认、完整候选校验及历史；Product 上下文仅保留已有修饰插入。当前范围、限制和验证入口见唯一 [Feature 能力表](../docs/architecture/current/solid-features.md#feature-能力表)。新增交互待手工验收，不累计实施日志。

后续按实际建模需求推进：其他生成器的合法历史创建及更多受约束移动；任意深层上下文编辑、跨层更新编排与柔性场景、静态干涉/间隙及交换验收仍未完成。具体边界分别归所属 current 主题，不把设计或接口存在当作交付。

沿用现有命令、稳定引用、权威求值、Naming 和补偿历史；每次完成创建/编辑/修复及必要的真实 Router/Worker、浏览器和热冷重建验证。暂停新增三维 Feature 类型，不扩展 AI/DSL、曲面或新求解框架。已完成或被替代的规划直接删除，历史由 Git 保留。
