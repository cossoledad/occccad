# CAD 核心主线

当前长任务：完善二维草图与 Solid Feature 的整体参数化设计、连续操作、依赖诊断和修复，并扩展典型实体特征。2026-11-07 已授权连续实施以下全部阶段；原“暂停新增三维 Feature”约束撤销。勾选表示实现与约定验收均完成；未勾选项目不得写成 current 保证。

## 本轮范围与顺序

| 阶段 | 实施范围 | 完成条件 |
|---|---|---|
| A：设计输入 | 显式尺寸工具与后续编辑；统一单位、表达式和参数补全；尺寸引用更换；草图与生成器往返 | 正式尺寸/ParameterId、下游实体、预览/取消、Undo/Redo 贯通 |
| B：局部消费与修复 | 合法区域独立消费及区域变化影响；Part 依赖查看；根因定位、健康历史对照和显式替换 | 开放草图不阻断无关合法区域；失效不猜绑；修复保留对象身份 |
| C：关联与操作 | 关联偏移；合法历史创建扩展；约束推断、自由度引导；紧凑操作面板 | 关系持续求值；手势只生成一次正式操作；取消和迟到响应安全 |
| D：典型生成器 | 更多关联终止与偏移、薄壁、Sweep | 精确构造、完整 Naming、创建/编辑/修复和热冷重建 |
| E：工程与复用 | 多点工程孔及孔参数；放样连续性；有明确适用范围的特征重执行 | 支撑、成员位置及终止按当前输入重新求值 |
| F：整体收口 | 完整零件检验、性能边界、浏览器流程、领域文档整理 | 实际执行记录与未覆盖边界明确；current、guides 和主线状态一致 |

2026-11-08 操作精简：移除实体尺寸手柄与绘制时创建尺寸的数值框；测量、参数与接口独立分类，Sketcher 不混合实体命令。扫掠路径及薄壁线链统一视区选择。正式尺寸/公式、推断关系、历史和权威预览合同保留。

## 共同合同与检验

复用 Part → Body → Feature、稳定实体/ParameterId、PersistentSelection、Publication、InstancePath、粗粒度 Worker、完整 Naming、Command/ChangeSet/CAS 和补偿历史；不引入第二套领域/历史/选择真相。新增能力保留既有身份及单位语义，扩展定义和版本化求值策略，不按几何相近静默改绑。草图往返保留已明确提交的操作；不以改写旧 Revision 实现取消。

每项先设计可执行检验再收口；实现期间执行局部回归，整体逻辑完成后追加组合检验。覆盖值/公式/单位、预览不写 Head、一次提交、未知回执幂等、上游更新、失效/修复、Undo/Redo、重开和冷重建。涉及实体和协议必须经过真实 Router/Worker；交互另有 browser-live 验收。原始报告归 build/agent-check/，未执行、skip、Mock 或仅算法测试不算全链通过。

商业参考：本机 CATIA `online/prtug_C2/prtugbt0501.htm`（Pad 草图往返；尺寸手柄当前不采用）、`online/dysug_C2/dysugbt1020.htm`（关联轮廓偏移）、`online/cfyugprt_C2/cfyugprtdefine.htm`（当前工作对象），以及官方 Onshape/SOLIDWORKS 帮助。参考行为与当前实现分别表述。
