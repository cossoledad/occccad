# CAD 核心主线

当前重点：Hole 到平面关联终止及关联输入维护。三种孔型复用正式终止引用、上游解析、精确裁剪与显式修复；沉孔入口检查完整工具。LOCAL 修改仍限当前 Product 直接 Part，已保存模块支持嵌套读取与冷热重建；删除绑定统一为恢复已接受零件默认并刷新转发接口。当前能力和限制见[发布与关联设计](../docs/architecture/current/product-assembly.md#发布与关联设计)与唯一 [Feature 能力表](../docs/architecture/current/solid-features.md#feature-能力表)。不累计实施日志。

后续按实际建模需求推进：贯穿 Hole 阵列/镜像工具复用、切除范围、更多合法历史插入/移动；任意深层上下文编辑、跨层更新编排与柔性场景、静态干涉/间隙及交换验收仍未完成。具体边界分别归所属 current 主题，不把设计或接口存在当作交付。

沿用现有命令、稳定引用、权威求值、Naming 和补偿历史；每次完成创建/编辑/修复及必要的真实 Router/Worker、浏览器和热冷重建验证。暂停新增三维 Feature 类型，不扩展 AI/DSL、曲面或新求解框架。已完成或被替代的规划直接删除，历史由 Git 保留。
