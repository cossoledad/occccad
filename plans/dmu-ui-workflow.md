# DMU 对话框与操作流程整改

2026-10-11。依据维护者的新反馈，继续沿用[机构位姿与独立约束设计](dmu-mechanism-redesign.md)，持续调整用户操作和命令呈现；平面方向和机构操纵贯通既有正式约束、求解及历史边界。

## 参考与现有缺陷

CATIA B33 `control/KinEnglishC2.viewdoc` 引用的 `online/kinug_C2/kinugbt0701.htm` 使用四个顺序选择字段和角度命令；`kinugbt0201.htm` 将运行时间、步数、播放、暂停和定位放在同一个 Simulation with Laws 对话框；`kinugbt0202.htm` 的坐标滑块同样属于仿真对话框；`kinugbt0205.htm` 明确关闭后保留位置。已核对页面和对话框图片，不推断 CATIA 内部实现。

现有旋转接合字段按零件端组织，几何只显示“已绑定”，用户无法确认圆柱面解析的轴、定位面或将生成的两个约束。现有仿真先打开运行设置，再打开结果对话框；播放还暴露为全局命令。冻结回放关闭前禁止定义编辑合理，但这使工具栏看起来只剩播放，而且局部操作错误依赖全局 Registry 状态。

## 用户流程与界面

| 阶段 | 入口和内容 | 完成及失败行为 |
|---|---|---|
| 定义机构 | 入口只编辑已选机构，否则立即新建；固定件、接合、角度命令、规律及模拟沿用正式保存 | 退出删除本会话未操作的空机构；已有机构或确认过定义／移动的机构保留 |
| 旋转接合 | 显示所属机构和名称；“轴线重合”两字段及“轴向定位”两字段，顺序仍为两轴、两面 | 精确 inspect 后绑定；显示零件和几何类型；允许替换/清除；清除轴同时清除该端平面 |
| 几何来源 | 轴字段接受轴、直边及可解析轴线的圆柱面/圆边/圆锥面；定位字段接受基准平面或平面面 | 同一端面属于对应轴的零件，两端是不同零件；曲面不能冒充定位平面 |
| 参数与约束 | 偏移默认 0、平面方向默认同向，可设相对；角度命令独立勾选；角零位、旋转方向、限位置于展开项 | 生成轴线重合与平面偏移两条机构约束，不自动创建产品约束；完整且权威预览通过才保存 |
| 按规律仿真 | 工具栏“运行仿真”打开单个“仿真与回放”对话框，选择已保存仿真、查看规律/时长/帧数，点击计算 | 对话框保持打开，显示任务进度和“停止计算”；后台任务不因关闭自动取消 |
| 结果回放 | 双击对应模拟下独立结果节点打开指定 Job；起点/终点、前后单步、播放/暂停、时间滑块和时间输入全为局部控件 | 冻结版本下连续显示，定位时间两位小数；确认和转换使用完整计算帧，没有帧的失败运行仍展示诊断 |
| 结束回放 | 页脚“确定／取消”；标题关闭和 Esc 等同取消 | 确定将当前时间对应的合格计算帧权威保存为机构位置，失败保留对话框。取消不写 Revision，恢复机构已确认位置；历史版本恢复当前已确认机构位置 |
| 转换 | 工具栏统一入口：编辑时使用已确认机构位姿，回放时暂停并使用实际计算帧；520 px 宽度和“确定／取消”页脚 | 取消计划返回原回放及同一帧；转换成功回装配设计。继续保留显式独立转换与一次 Undo/Redo |

工具栏不提供播放、暂停、单步、复位或取消后台任务，搜索也不保留这些全局命令。“运行仿真”和每个结果节点双击是同一个对话框的两个入口；取消结果选择下拉框和全局“已保存结果”。打开期间禁止同时修改定义，视图导航保持可用；关闭后恢复正常定义操作。停止计算与停止播放分别命名，不混用取消。

终态结果右键删除只隐藏对应 Job 的用户入口，保留定义、Revision 和制品审计；对话框不提供删除按钮。命令对话框使用“确定／取消”，具体行为由标题和字段表达。

播放使用视口时钟，位姿更新不重建几何；相邻帧间使用统一时间的刚体螺旋显示插值，避免偏心旋转走直线。时间字段每 50 ms 更新并显示两位小数。帧间姿态属于显示近似，暂停、单步、确定和转换仍定位到计算样本。

## 实现边界与验收

Registry 只拥有打开/结束领域命令；播放控件直接操作对话框会话，不能启动另一个 CommandOperation。运行前台的完成回调仅在原对话框会话仍有效时显示，关闭后的迟到结果不能抢占视口；Job/Artifact 独立保留。转换是明确的子流程，取消返回仿真而不是留下无对话框冻结状态。

复用 FeatureSelectionSession、正式 inspect/preview/SAVE、ApplicationDisplay 与现有 CAS；不增加拾取控制器或从 Mesh 猜测支撑。新增轻量场景覆盖清除/选择顺序与命令目录；浏览器覆盖真实字段、局部播放、关闭后继续编辑、迟到任务及转换返回。真实 API/Worker 验收另行验证圆柱面/平面支持和实际仿真，Mock 不提供数值证据。

本次不扩展单坐标交互试动、多驱、传感器、速度图、动力学或 CATIA 录制功能。

## 2026-10-11 体验细化

- 支撑字段、单位、偏移／平面方向及角度命令足够表达输入；保存是否可用表达预览资格，不重复展示选择计数、教程和内部事务说明。错误保留可展开诊断。
- 平面方向与旋转正负方向是两个参数。平面方向进入普通 Offset，第二端轴符号和角度坐标随支持法向一致调整，禁止只改 UI 标签。
- 固定件与多实例化优先消费合法三维／树预选；没有预选时进入整实例拾取，高亮也是整实例，禁止默认第一个零件。嵌套选择按 owning Product 的路径定位。
- 仿真结果来自现有用户可见 Job 列表，按正式 studyId 挂到模拟下；每个节点只打开自己的 Job。播放期间的冻结树也投影结果，定义修改继续受会话门禁。
- 移动组件只在普通机构编辑时使用现有操纵器。Session 绑定机构，原 Product 真相与机构求解模型分开；final 候选核验机构自由度与驱动资格，保存成员位姿并保留 Product 约束，由原 token/CAS/Undo 机制提交。
