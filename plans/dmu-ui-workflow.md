# DMU 对话框与操作流程整改

2026-10-11。依据维护者的新反馈，继续沿用[机构位姿与独立约束设计](dmu-mechanism-redesign.md)，本次调整用户操作和命令呈现，不改变求解或持久身份合同。

## 参考与现有缺陷

CATIA B33 `control/KinEnglishC2.viewdoc` 引用的 `online/kinug_C2/kinugbt0701.htm` 使用四个顺序选择字段和角度命令；`kinugbt0201.htm` 将运行时间、步数、播放、暂停和定位放在同一个 Simulation with Laws 对话框；`kinugbt0202.htm` 的坐标滑块同样属于仿真对话框；`kinugbt0205.htm` 明确关闭后保留位置。已核对页面和对话框图片，不推断 CATIA 内部实现。

现有旋转接合字段按零件端组织，几何只显示“已绑定”，用户无法确认圆柱面解析的轴、定位面或将生成的两个约束。现有仿真先打开运行设置，再打开结果对话框；播放还暴露为全局命令。冻结回放关闭前禁止定义编辑合理，但这使工具栏看起来只剩播放，而且局部操作错误依赖全局 Registry 状态。

## 用户流程与界面

| 阶段 | 入口和内容 | 完成及失败行为 |
|---|---|---|
| 定义机构 | 工具栏提供新建、固定件、旋转接合、角度命令、规律和仿真定义 | 正式保存后回到机构编辑；取消回命令前基准 |
| 旋转接合 | 显示所属机构和名称；“轴线重合”两字段及“轴向定位”两字段，顺序仍为两轴、两面 | 精确 inspect 后绑定；显示零件和几何类型；允许替换/清除；清除轴同时清除该端平面 |
| 几何来源 | 轴字段接受轴、直边及可解析轴线的圆柱面/圆边/圆锥面；定位字段接受基准平面或平面面 | 同一端面属于对应轴的零件，两端是不同零件；曲面不能冒充定位平面 |
| 参数与约束 | 偏移默认 0，可设非零；角度命令独立勾选；零位、方向、限位置于展开项 | 对话框明确生成轴线重合与平面偏移两条机构约束，不自动创建产品约束；完整且权威预览通过才保存 |
| 按规律仿真 | 工具栏“运行仿真”打开单个“仿真与回放”对话框，选择已保存仿真、查看规律/时长/帧数，点击计算 | 对话框保持打开，显示任务进度和“停止计算”；后台任务不因关闭自动取消 |
| 结果回放 | 同一对话框选择已保存结果；起点/终点、前后单步、播放/暂停、时间滑块和时间输入全为局部控件 | 冻结完整帧显示；没有帧的失败运行仍展示诊断，不显示空白播放状态 |
| 结束回放 | 显式关闭、标题关闭及 Esc 使用同一完成流程 | 当前版本的合格帧权威保存为机构位置，成功后解除冻结并恢复定义按钮；失败保留对话框和帧。历史版本恢复当前已确认机构位置 |
| 转换 | 工具栏从机构已确认位置转换；回放对话框从选定帧打开转换计划 | 取消计划返回原回放及同一帧；转换成功回装配设计。继续保留显式独立转换与一次 Undo/Redo |

工具栏不提供播放、暂停、单步、复位或取消后台任务，搜索也不保留这些全局命令。“已保存结果”和“运行仿真”是同一个对话框的两个入口。打开期间禁止同时修改定义，视图导航保持可用；关闭后恢复正常定义操作。停止计算与停止播放分别命名，不混用取消。

## 实现边界与验收

Registry 只拥有打开/结束领域命令；播放控件直接操作对话框会话，不能启动另一个 CommandOperation。运行前台的完成回调仅在原对话框会话仍有效时显示，关闭后的迟到结果不能抢占视口；Job/Artifact 独立保留。转换是明确的子流程，取消返回仿真而不是留下无对话框冻结状态。

复用 FeatureSelectionSession、正式 inspect/preview/SAVE、ApplicationDisplay 与现有 CAS；不增加拾取控制器或从 Mesh 猜测支撑。新增轻量场景覆盖清除/选择顺序与命令目录；浏览器覆盖真实字段、局部播放、关闭后继续编辑、迟到任务及转换返回。真实 API/Worker 验收另行验证圆柱面/平面支持和实际仿真，Mock 不提供数值证据。

本次不扩展单坐标交互试动、多驱、传感器、速度图、动力学或 CATIA 录制功能。
