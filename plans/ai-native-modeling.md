# AI 原生建模后续计划

> 前置框架已实现，当前范围见[操作、查询、任务与显示](../docs/architecture/current/automation.md)。本阶段不连接真实 AI；DeepSeek 为后续 API 测试候选，尚无模型 SDK、凭证配置或调用。本文仅保留未完成工作。

## 继续保持的边界

LLM 利用已有语言和 CAD 概念知识理解任务；当前事实、身份、单位与几何正确性由应用和权威 evaluator 提供。内置模型工具调用、MCP 和 CLI 复用同一 Automation 合同，模型适配不产生另一套命令、权限、Preview 或历史。

上下文只加载目标/硬约束、快照、当前对象、少量操作合同与检查点。稳定引用、预算、完整性、未知提交结果恢复、人工接管及真实显示确认不能因节省 token 而削弱。

## 待实施范围与退出条件

| 方向 | 剩余工作与退出条件 |
|---|---|
| 模型适配与规划循环 | 用户确认实际接入时，核对候选 API 的官方工具调用、结构化输出、流式、超时和 usage 合同，将供应商格式翻译到现有 Tool/Call/Result。补充受控循环、用户澄清、任务级工具/时间/费用预算与停止策略；可先使用 DeepSeek 做真实请求测试，不提前绑定 SDK 或公开兼容承诺。 |
| 长任务与动态计划 | 在现有持久检查点之上增加结构化用户硬约束、分段规划、受控追加/修订和来源记录；恢复必须重读事实，区分已确认约束与模型假设。当前最多 32 步的固定计划不冒充任意长 Agent 任务。 |
| 查询与大树 | 按真实场景补派生索引、局部依赖与聚合、按需子树、完整 selectionSet、定义/occurrence 复用和跨文档快照。当前有界定义分页不等于全树懒加载；样本不能成为批量写入的完整对象集。 |
| 操作与 recipe | 按用户切片扩展操作包、适用能力和小型示例，继续共用 schema/编译校验与领域实现。沉淀版本化 recipe，批量处理由确定性代码执行；操作合同与实际 handler/Worker 能力保持一致。 |
| AI 对话 UI | 将模型提议、澄清和作用范围映射到现有步骤面板；按发送时快照冻结选择，提供候选定位和接管。补充任务通知/订阅，避免规模扩大后依赖完整任务轮询。 |
| 外部入口与领域 | 增加 MCP Server、CAD CLI 和可替换 Runtime adapter；再按真实需求扩展装配、Publication 与跨文档事务。验证各入口使用同一权限、基线、回执和失败语义。 |
| 高阶执行 | 多步整体预览需要 draft workspace 或等价候选模型；整任务撤销需要依赖/人工编辑冲突合同；沙箱脚本须有独立资源与副作用边界。均按独立场景评估。 |

## 验收与度量

先以当前 Part 最短链验证真实模型调用，再扩展数万节点、重复定义、复杂拓扑和长步骤任务。覆盖同名/重复 occurrence、PINNED/历史快照、共享定义影响、查询截断、预算耗尽、过期候选、并发人工编辑、未知提交结果、求解与显示失败。

按固定模型/版本和任务集记录成功率、总输入/输出 token、缓存命中、调用轮数、修复次数和端到端延迟；字节预算与合成节点测试不替代实际 token 或工业容量测量。后端、原生 Worker 和真实浏览器证据分别记录，静态设计不计为通过。
