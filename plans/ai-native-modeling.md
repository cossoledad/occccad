# AI 原生建模后续计划

> 已实现合同见[持续建模架构](../docs/architecture/current/automation.md)。持久 Run、默认无累计封顶、后台执行、逐调用账本、冻结选择、分段观察与普通轴孔验收不再列为待建框架。本页只保存剩余范围，验证记录独立维护。

| 方向 | 剩余工作与退出条件 |
|---|---|
| 真实模型质量 | 用[固定小样评测入口](../services/cmd/occccad-ai-eval/README.md)积累跨模型/配置的成功率、澄清、修复、延迟与用量基线；受控 Provider 通过不能替代线上推理质量。金额估算须有价格版本，百万真实付费压测需另行授权。 |
| 大树与查询索引 | 为真实数万节点数据补持久索引、局部依赖/聚合、按需子树及超大集合服务；目前受限定义解析与分页不代表工业容量。保留完整性、快照与源 ACL。 |
| 更广目标与 recipe | 扩充带用户来源的结构化目标检查、版本化操作示例及领域 recipe。当前必需检查覆盖矩形/拉伸/圆角/保护选择/普通轴孔，未支持目标不能靠模型文案完成。 |
| 复杂 Product | 补 ContextVariant 专属几何制品的 occurrence 查询与验证，不替用普通 Part BRep；扩展更复杂 Publication/装配组合及接触。跨文档原子写独立设计。 |
| 更多 UI 完成桥 | 在保留先记录handoff、精确请求身份和取消/未知状态的前提下，为更多原工作台工具提供安全完成回报；没有桥的工具仍等待人工，不猜测对话框关闭即完成。 |
| 运维与外部入口 | 按实际部署需要补主密钥轮换、集中凭证管理、任务通知/订阅、可替换Provider适配；MCP Server/CAD CLI复用同一权限/Preview/回执合同，不新增写入体系。 |
| 高阶执行 | draft workspace整体预览、带依赖/人工编辑冲突的整任务撤销、受约束脚本运行时均按独立场景设计，不作为当前持续任务前置。 |

运行容量、原生Worker、浏览器与线上模型证据分别记录；字节工作集和合成usage不等于实际模型token节省、百万付费消耗或生产吞吐保证。
