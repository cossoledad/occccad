# AI 原生建模后续计划

> DeepSeek/OpenAI 格式对话、按账号 Key、受控规划、全命令发现、模型/思考度/调用预算选择及 Part/Product 定义步骤执行已实现，当前范围见[自动化与对话合同](../docs/architecture/current/automation.md)。本文仅保留未完成工作；受控协议测试不等于线上模型质量验收。

## 继续保持的边界

LLM 利用已有语言和 CAD 概念知识理解任务；当前事实、身份、单位与几何正确性由应用和权威 evaluator 提供。内置模型工具调用、MCP 和 CLI 复用同一 Automation 合同，模型适配不产生另一套命令、权限、Preview 或历史。

上下文只加载目标/硬约束、快照、当前对象、少量操作合同与检查点。稳定引用、预算、完整性、未知提交结果恢复、人工接管及真实显示确认不能因节省 token 而削弱。

## 待实施范围与退出条件

| 方向 | 剩余工作与退出条件 |
|---|---|
| 线上模型评测与体验 | 用实际 DeepSeek Key 和固定需求集记录计划正确率、单位换算、澄清、错误恢复、token/cache usage 与延迟；当前受控协议服务只验证应用链路。按体验需要增加流式回复与金额预算，继续使用同一受控 Host，不新增写入通道。 |
| 长任务与动态计划 | 在现有持久检查点之上增加结构化用户硬约束、分段规划、受控追加/修订和来源记录；恢复必须重读事实，区分已确认约束与模型假设。当前最多 32 步的固定计划不冒充任意长 Agent 任务。 |
| 查询与大树 | 按真实场景补派生索引、局部依赖与聚合、按需子树、超大集合、持久查询索引、定义/occurrence 复用和跨文档快照。当前有界定义分页不等于全树懒加载；样本不能成为批量写入的完整对象集。 |
| 操作与 recipe | 在已有全目录桥接和圆角等简短合同之上，按用户场景补简短操作、适用能力和小型示例，降低复杂 DTO 规划成本。沉淀版本化 recipe，批量处理由确定性代码执行；操作合同与实际 handler/Worker 能力保持一致。 |
| 对话与凭证扩展 | 补跨 Revision 选择集生命周期、跨轮硬约束与可审计计划来源、长历史分页和任务通知/订阅；评估主密钥轮换与集中凭证管理。当前只有近期对话工作集、按需任务检查点、自动生成本地主密钥和轮询。 |
| 外部入口与领域 | 增加 MCP Server、CAD CLI 和可替换 Runtime adapter；继续验证复杂装配/Publication 参数组合，并按实际需求扩展 occurrence 上下文与跨文档事务。验证各入口使用同一权限、基线、回执和失败语义。 |
| 高阶执行 | 多步整体预览需要 draft workspace 或等价候选模型；整任务撤销需要依赖/人工编辑冲突合同；沙箱脚本须有独立资源与副作用边界。均按独立场景评估。 |

## 验收与度量

先以当前 Part 最短链完成线上 DeepSeek 模型效果与成本基线，再扩展数万节点、重复定义、复杂拓扑和长步骤任务。覆盖同名/重复 occurrence、PINNED/历史快照、共享定义影响、查询截断、预算耗尽、过期候选、并发人工编辑、未知提交结果、求解与显示失败。

按固定模型/版本和任务集记录成功率、总输入/输出 token、缓存命中、调用轮数、修复次数和端到端延迟；字节预算与合成节点测试不替代实际 token 或工业容量测量。后端、原生 Worker 和真实浏览器证据分别记录，静态设计不计为通过。
