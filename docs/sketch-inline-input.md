# 草图当前动作与 inline 参数输入

草图当前动作继续由工具的 `SketchCommandState` 推进。状态栏显示 actor 的当前 role、接受/所需数量、字段入口与完成入口；不从中文提示解析阶段或重建选择状态。ToolManager 拥有工具生命周期，Viewport 只转发状态与动作，Workbench 仅显示投影。

`presentation=inline` 时，视口只显示 `input.fieldIndex` 对应字段的引线数值，不显示常驻输入卡片；所需参数自动聚焦无边框编辑，Enter 接受，失焦不提交。`input.id` 表示焦点请求代际，hover 更新不重置输入焦点或数值草稿。数值、单位和表达式原文通过 field action 回到 actor；长度使用当前文档单位，角度为 deg；已打开草稿以 actor 的 displayUnit 保持输入单位，不因外部偏好改变重新解释数值。Tab 切换字段，Enter 单次确认，Esc 退出整个所属工具；失焦不取消工具，IME 和重复按键不触发确认。没有输入请求时不常驻参数面板。直接镜像/倒角的次级定义通过状态栏“选项”按需弹层修改；双距离/距离角度的第二字段可由状态栏字段入口或 Tab 切入，仍通过同一 actor action 保存原文。普通单半径/单距离不增加空选项面板。草图编辑工具共用此内联路径；尺寸编辑对话框保留值/表达式、定位、名称、删除、停用和参考尺寸；不再显示引用更换和更多设置。逻辑约束编辑仍可受控更换引用。

所有草图按钮单击单次、双击明确请求连续。尺寸的选择、放置和数值阶段由尺寸工具推进；首线在定义阶段仍可接受明确第二对象，锁定长度或空白放置才接受单线定义；进入 Placement 后引用冻结。镜像先选轴再选来源集合，Enter/完成入口提交；修剪默认删除命中，hover 只展示候选区间。确认仍走既有正式 Sketch 命令，未知结果保留原 requestId/operations 并查询回执，阻止新编辑，不因输入 UI 消失或退出工具宣称请求已撤销。

悬停引用、已接受选集、尺寸预览和修剪区间具有独立生命周期。草图绘制与拾取共享角色规则：构造几何及其端点低于普通几何；尺寸引线低于普通几何，文字与逻辑标记单独呈现；候选、已选和修剪区间覆盖常规显示。同位置角色拾取优先普通几何，离开重叠区仍可拾取构造元素；虚线间距按投影后的 CSS 像素更新，不影响实体身份或候选优先级。普通选择和工具角色使用同一模型屏幕距离规则；尺寸通过文字/标记拾取，引线不抢夺曲线点击。视图引用反馈只高亮几何，不显示 #1/#2 编号。

尺寸文字使用附着支持平面的透明文本 Mesh，无白色描边，基线沿尺寸线或角度标注弧的局部切线排列，正常/悬停/选中/诊断颜色由材质状态直接设置，字形始终保持不透明，不叠乘已有文字颜色；只有缩放尺度跟随相机；斜视时正常发生平面投影缩短，不自动转向相机。圆角、倒角候选生成临时的正式尺寸定义，复用尺寸 layout/renderable；它们不是持久写入。参数编辑命中区跟随同一尺寸锚点，编辑时只隐藏当前临时文字，保留其引线与其它尺寸。两曲线选取完成后自动聚焦数值；拖动 R/距离标注只改变引线位置，不改变数值或引用。确认仍由原有复合命令建立持久尺寸及稳定 ParameterId。

Select 支持草图框选：从左往右为完整包含，从右往左为交叉选择，Ctrl/Meta 增加到现有选择，Esc 取消框选。Delete/Backspace 通过现有原子删除操作处理当前本地实体/普通约束；文本编辑和尺寸面板内不会触发几何删除，待确认回执阻止重复编辑。连续创建的提交屏障阻止新手势，但原指针的 up 仍返回原处理者释放 capture。

尺寸编辑对话框打开时冻结尚未结束的视图动画，保留当前相机位置和方向；按所选导航配置继续支持鼠标导航及中键组合。面板保留模型修改屏障，仅引用替换允许对象拾取。数值、表达式与引用草稿经既有只读 Preview 计算几何和尺寸显示；代际、版本、occurrence 与 AbortSignal 防止迟到覆盖，取消恢复原显示。非法草稿/预览错误只在面板内反馈，不产生历史。提交回执继续由 Engine 管理，正常等待不显示底部提示框，未知回执在状态栏提供恢复入口。

工具栏将同类创建方式、样条控制及尺寸组合并为分体按钮；下拉选择立即执行并在本页浏览器会话中记住默认方式。主按钮仍遵守单击单次、双击连续规则，仅保留“修剪”生产入口。操作语义参考 Onshape 官方 [Trim](https://cad.onshape.com/help/Content/Sketch/trim.htm)、[Split](https://cad.onshape.com/help/Content/Sketch/sketch_split.htm) 和 [Extend](https://cad.onshape.com/help/Content/Sketch/extend.htm)；直接拖动延伸按本产品输入合同实现。修剪删除命中区间，无边界时整条高亮并删除；分割保留形状和正式 Coincident。延伸选择本地直线、圆弧或椭圆弧后，移动并点击目标，或直接拖动释放；自由目标投影到解析支撑，捕获边界时由精确交点构造 Coincident/PointOnObject。Spline 无定义的外推明确拒绝。构造转换直接点选，合法主动预选作为一次整体操作，不弹表单。统一缩放不支持，服务端拒绝 scale 请求。

所有草图临时几何、尺寸、角色候选、吸附和只读尺寸编辑候选挂入 Engine 的同一非拾取 preview layer；工具/模态会话继续拥有草稿、版本和请求代际，显示层不接受引用、不产生历史。补弧、闭合、偏移和样条编辑复用同一操作定义请求只读候选；结果未返回时接受的 Enter 等待当前候选，取消或定义变化使旧提交意图失效。选集仍由选择系统高亮。生成圆角/倒角的 SAME_SUPPORT 不再重复添加裁剪点落支撑方程；端部相切引用连接的裁剪曲线，求解编译去重已有端点连接的支撑定位。圆角补弧翻转被视为分支失败，使用现有尺寸渐进求解，不伪改几何。

移动、旋转和复制在源集合完成后显示平面手柄，合法主动预选直接进入手柄阶段。拖动箭头/平面移动，弧形手柄旋转，中心调整基点；释放提交，Esc 取消未提交草稿。移动和复制允许同一操作组合平移与旋转；旋转只显示旋转手柄。失败保留源对象，重新拖动可修正；不会自动解除固定或公式关系。

圆弧和椭圆弧按住 Ctrl 临时反向，释放恢复默认，R 切换默认方向；参考 [AutoCAD ARC 方向规则](https://help.autodesk.com/cloudhelp/2023/ENU/AutoCAD-Core/files/GUID-0B1DFB99-1508-4210-8C8A-333E94DF1E4A.htm)。延伸的方向来自已接受端部及有向曲线，选择源曲线时按住 Ctrl 可选择另一端；后续悬停不更改端部。圆弧显示圆心和端点，椭圆/椭圆弧显示中心、焦点及主次轴控制标记；焦点和轴尖为派生显示，不增加可自由拖动的模型点。

分割显示投影位置，在屏幕阈值内优先吸附落在目标曲线上的已有端点、独立点及解析交点。确认后服务器精确验证，保留稳定连接。可先主动预选直线，再分割交叉位置，避免重叠曲线争抢角色。Delete 在全局选择模式下处理视口/树中具有删除能力的对象，文本输入、模态编辑和正在提交的命令不受影响。

## 人工步骤

1. 激活镜像/修剪/圆角，观察状态栏当前动作及已接受数量；空白鼠标移动不重新解释阶段，也不出现完整常驻选项面板。
2. 选够对象后自动聚焦半径、偏移或尺寸，检查引线数值；拖动 R/距离标签只调整标注位置。尝试表达式和 in/cm；hover 不清空或重新全选正在编辑的文字。
3. Tab 切字段、Enter 确认一次、IME 输入不确认；输入框 Esc 应直接退出所属工具。单纯点击别处或失焦不自动退出工具。
4. 连续修剪/分割/圆角成功后继续下一组；Mirror 单次成功回选择，双击模式可连续。失败保留草稿，未知响应只查询原请求，不能再次生成重复操作。
5. 打开高级编辑和已有尺寸编辑，确认选项、参考模式、取消与未知回执屏障仍可用；尺寸值默认全选，可直接键入后 Enter。在 Product 内编辑 Part 草图重复以上步骤，宿主与标签保持。

6. 完整十步主闭环和引用/回执检查见[草图交互验收](sketch-ux-02.md#人工验收)。

7. 双击直线/圆弧，连续完成至少两条；分别检查第二次的候选、起终点及 Esc 退出。
8. 普通选择中左右两个方向框选，检查包含/交叉差异；Ctrl 增选，Delete 删除，Undo 恢复。输入框内 Delete 只编辑文本。
9. 缩放、旋转视角检查构造线虚线与普通曲线重叠层级、同位置拾取和尺寸平面朝向；文字不出现白色描边。
10. 双击尺寸，确认相机不跳变；修改值/表达式等待几何预览，继续按当前导航配置转动/平移/缩放；取消恢复模型显示，确定后检查权威尺寸。


11. 选择直线/圆弧/椭圆弧后拖动释放延伸，或点选目标；捕获另一条边界后检查交点连接。修剪去掉多余段，再检查闭合反馈；撤销/重做/重新打开保持端点身份。
12. 孤立圆分割两次成两弧，仅修剪其中一弧；无边界修剪应整条高亮。直接点选转换 Construction，检查不弹表单。失败时状态栏显示原因，仅有受影响关系才提供明确的解除/撤回入口，普通操作不要求解除关系。

13. 按住 Ctrl 绘制圆弧/椭圆弧，再释放 Ctrl 检查候选方向恢复；完成后检查中心、焦点及轴标记。
14. 延伸圆弧到斜直线，预选该直线启动分割，在接触附近移动检查吸附，再点击分割。撤销/重做并重新打开检查两段和连接。
15. 预选多个元素启动移动/复制，拖动平面和箭头并往返，释放一次提交；旋转手柄转动，中心手柄只改基点。固定/受约束对象失败后应能重新拖动，Esc 清除候选。
16. 视口或树选择可删除元素按 Delete，然后 Undo；选择不支持删除的节点不产生请求。输入字段中 Delete 仍只删除文字。
