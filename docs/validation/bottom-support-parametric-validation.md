# Bottom Support 参数化体验验收

2026-10-05。本轮交付参数与引用链路，不宣称重新完成目标 STEP 几何等效或 WebGL 人工验收。

## 统一规则

- XYZ 与 Part 原点的树选择、hover、视图区选择共享文档、Revision 与 occurrence；原点随 Part 实例位姿变换。
- 基准定义保存来源、旋转轴、平移方向；先右手旋转，再平移。角度/距离沿用 ParameterDefinition/checked AST，数值框架随求值更新。自定义基准可编辑；引用不改变来源所有权。
- 标准/基准面轴、草图直线、已连接的投影直线、精确实体平面/直线边按角色使用；拓扑输入明确绑定 PersistentSelection、Revision 和 Body 来源阶段。循环、间接下游、缺失/歧义及非直方向被拒绝。
- 原点/轴投影复用 ExternalGeometry 和现有 RPC。轴投影是无限方向，垂直时为点；规范方向的两个数值点不是有限端点或边长。方向投影不能冻结成任意有限线段。
- 参数管理器加宽、限高、搜索，树按所属 Feature/Datum 分组。插入引用使用当前别名，持久 AST 绑定稳定 ID。长度表达式显式写单位，例如 `r_1 + 5 mm`；提交前显示权威计算值/错误。

## 人工步骤

1. 刷新工作台，选 Origin 的 X/Y/Z 与原点；核对高亮单个对象、视图区 hover 定位对应树节点。Product 的两个同 Part 实例分别验证。
2. 新建 `tilt`（30 deg）、`height`（20 mm）、`r_1`（5 mm）、`r_2`（10 mm）。编辑 `r_2`，插入 `r_1` 并追加 `+ 5 mm`，计算值应为 10 mm。
3. 创建关联基准面：来源 XY，旋转轴 X，角度 `tilt`，平移方向 Z，距离 `height`。在其上创建草图，投影 Part 原点、标准轴和基准轴；斜投为方向、垂直为点。
4. 在 Bottom Support 的相应尺寸中引用上述参数；修改倾角、高度及 `r_1`，核对定义、草图和后续实体一起更新。检查预览/取消、基准编辑、Undo/Redo、关闭重开。
5. 尝试错误量纲、自引用和引用使用本基准的下游草图线，检查失败提示与原 Head 保留。

剩余边界：一般曲线/圆弧/斜圆与面投影未扩展；跨 occurrence 的局部基准输入仍需既有 Publication/Context 机制。本轮没有扩大完整轴系定义编辑或装配世界参考建模能力。

## 实机反馈后的投影修复

- 根因：工具切换未刷新基准显示；投影拾取过滤只接受 Edge/Vertex；投影工具缺少树选择入口。现统一树/视图输入，按文档、Revision、occurrence 校验，提交中不重复写入；原点按 POINT 捕获类别处理。
- `CAD_DIAGNOSTIC 01a10d25-c3b4-7f3a-9487-29fdc6a6dc07/20261006T042730.962850346Z-cd8b897686593a7c`：有效 LINE 边被当作退化投影拒绝。源方向 `(0,-1,0)` 与支撑法向一致；修复后为关联点，保留阵列成员的 EDGE Naming。按诊断支撑/边参数提取最小 C++ 回归，结果 `(-120,0)`。
- 定向验收：进入草图后启动“投影”，核对当前实例原点/XYZ/基准轴显示与 hover；分别从树和视图区投影；在原文档重试垂直边，检查关联点及 Undo/Redo、关闭重开。完成/取消投影后显示恢复。面显示不代表支持面投影。
- 验证边界：诊断最小几何回归与受控真实 Router 生命周期分别验证；不将其视为原文档完整实机验收。
