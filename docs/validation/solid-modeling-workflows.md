# 实体建模工程验收

[审计基线](../references/solid-modeling.md)与[CAD 主线](../../plans/cad-core-roadmap.md)定义范围。以下为设计验收用例，执行记录归 build/agent-check/。尺寸以 mm 计。

| 零件及制作顺序 | 设计变更 | 几何、身份与历史断言 |
|---|---|---|
| 斜壁仪表壳。在 XY 建 80×60 底座，拉伸 30；外侧拔模 3°，去顶面向内抽壳 2；另用已有近重合样条开口壳作回归 | 壁厚改 2.5，撤销并重做 | 剩余材料包含于原体；以开口外侧见证和真实差集检查多余材料；截面检查内壁与底部。失败时禁止发布成功制品 |
| 在筋顶高程的草图画跨越两侧壁的筋中心线，朝壳底延伸，厚 2.5；两端贴合斜壁 | 改底座宽和壁角，再编辑筋厚、反向和取消 | 筋根接到底面，两端到新内壁，材料不伸出外壳；平面截取实测厚度，原壳壁保留 |
| 安装法兰上画两排定位中心，用统一规格创建连接孔；在另一组端点建孔。外缘分别做 1×2 与距离 1、角度 30° 的倒角 | 改孔距、规格，交换倒角参照侧 | 核对解析孔径和位置、保留未改孔的持久引用；在垂直于边的剖面测两侧退距／角度 |
| 减速箱毛坯用穿过材料的基准面分割；在一侧加工维修孔，另一侧保留。另在完整外壁上分面，再只对一区域拔模 | 平移分割面；移动到体外检验失败；撤销后重开 | 分割前后总体积守恒，两侧公共截面相合，下游孔所属 Body 稳定；单纯分面体积不变，分面可独立选取 |
| 对称支架先作有限凸台和根部修饰，再分别用生成工具、净材料范围和整个阶段镜像；另设到斜面的切除并在成员处重执行 | 改凸台半径、斜面高度及阵列数量 | 核对实际选源、材料差、稳定槽位及确切终止边界；取消不推进 Head，重开与冷算均保留定义 |

每项从正式工作台创建和编辑，以 Router/Worker 返回的 BREP、Naming 和模型判定。预览、取消、提交、上游改参、失效修复、Undo/Redo、重开和冷重建分别留证。浏览器拾取与几何正确性分别记录。

## 自动化样件与判据

真实 Router 场景 `TestEngineeringFlangeThroughRouter` 从 40×40×10 毛坯开始，以正式命令提交、再读取 Body 制品测体积。每个分支独立建件，使任一失败都可定位。

| 分支 | 尺寸或操作 | 预期 |
|---|---|---|
| StandardHole | 在构造线起点与圆心各打一个贯穿孔，M4 改 M6 | 切削体积从 20π×2.25² 变为 20π×3.3² mm³ |
| Rib / DraftedRib | 平面底上的 20×2×6 筋；另作深 6、内宽从 20 到 26 的方形斜壁凹槽，从筋顶到槽底裁切跨壳线链 | 分别新增 240 和 176 mm³，槽内筋宽随深度变化 |
| SplitFace | 用 YZ 面分割毛坯顶面 | 材料仍为 16 000 mm³，正负两侧各能按 Feature 和稳定输出槽取得面；在负侧建草图，平移分面 5 mm 后支撑继续有效 |
| TwoDistances / DistanceAngle | 长 40 的边作 1×2 或 1 mm、30° 倒角 | 分别去除 40 和 20 tan(30°) mm³，侧壁上的新顶点退距分别为 2 mm 和 tan(30°) mm |

工作台场景 `flange asymmetric chamfer` 用视区预选边和邻面，核对预览期间 Head、提交后的参照、模式和切除量。复制使用 `TestLoftReplicationAndMirrorLifecycleThroughRouter` 与 `TestPatternReexecutionPerMemberTerminationRepairAndIdentity` 检查真实成员及引用。

工作台 `rib workbench picks` 从视区选择中心线，保存并重新打开改筋厚；`split a flange face` 从树选分割平面，再从视区选线端点和圆心，提交 M4 贯穿孔并核对成品体积。`GearboxPlanePartitionKeepsSignedSides` 在内核验证平移分割平面后的两侧体积、同一公共面、外移及相切拒绝。`TestGearboxSplitThroughRouter` 用 80×60×30 箱体毛坯验证业务身份。分型面位于 X=25，原 Body 保留正侧时两件分别为 99 000 和 45 000 mm³。将面移到 X=35，翻转保留侧，重开并分别选取两个 Body 的真实截面。两侧各钻一个 Ø4 贯穿孔后将面移回 X=28，两件材料分别为 50 400 − 120π 和 93 600 − 120π mm³。该流程还覆盖撤销、重做、抑制、恢复、拒绝相切预览以及失败预览期间 Head 保持原值。
