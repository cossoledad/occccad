# 对象属性与全局选项

对象数据用树右键“属性…”或 `Alt+Enter`，应用设置用顶部齿轮图标（提示“全局选项”，无按钮文字）。对象属性写 Revision；全局选项保存于当前浏览器，作用于所有文档。外观模型和 STEP 边界见[颜色材质](surface-appearance.md)。

## 入口与菜单

- **唯一可见的全局设置入口**是全局标题栏齿轮图标，在文档中心和所有工作台均可用，执行 `app.options`；命令搜索投影同一命令。右下角保留状态、单位/导航提示和当前工具动作。工具自己的“工具选项”与应用设置分开命名。
- **视区右键没有菜单**，原菜单组件、候选列表、事件回调和点击检测均已删除；保留浏览器原生菜单抑制、右键旋转和工具取消行为。选中面后可用 `Alt+Enter` 查看属性。
- **树菜单**按通用操作、显示/隐藏、删除/复制别名、`对象` 子菜单、底部“属性…”分组。定义编辑、工作对象、抑制、引用模式和重连等放在对象子菜单，只投影实际支持的能力。多选只显示可针对选集执行的操作，不把“编辑点击的单个对象”混入批量操作。
- 独立“重命名”“颜色材质”命令、注册和表单入口已移除。名称和外观统一在属性中；机构/关节/驱动/模拟名称复用属性表单，提交仍经既有 `SAVE_KINEMATICS`，不改产品约束。

顶部入口的选择是本软件的取舍：文档中心也需要配置新建默认值，顶部全局位置比仅工作台右下角更一致；无需重复增加“场景属性”按钮或工具栏分类。

## 对象属性

“基本 / 图形 / 信息”固定打开时的目标和基准 Revision。相机与选择变化不切换编辑目标；多选要求同一写入文档和基准版本，混合字段只写实际改动。

| 目标 | 可修改项 | 所有权 |
|---|---|---|
| 根文档 | 名称、描述、默认外观 | 当前 Part/Product |
| Body | 名称、整体与边线外观 | 原始 Part；装配中可仅覆盖当前 occurrence 外观 |
| 面 | 颜色、透明度、粗糙度、金属度、选择性 | 稳定拓扑 anchor；也可为宿主 occurrence 覆盖 |
| 特征/草图、用户基准面/轴 | 名称 | 原始 Part；标准基准面不可改名 |
| 组件实例 | 名称和外观 | 直接实例属当前 Product；嵌套名称为宿主别名 |
| 机构、关节、驱动、模拟 | 名称 | 当前 Product 的机构定义 |

作用范围、写入文档和版本明确显示。Inspector 保持只读；历史/只读上下文不能写入。透明度显示为 0–100%，模型保存 opacity=1−透明度；字段独立继承/自定义，整体修改保留分面属性。

外观通过可取消的防抖 PreviewCommand 返回正式投影，不创建 Revision。确定原子提交，取消清除预览；迟到响应不能覆盖新草稿。冲突保留修改，可重新加载基线；实例删除/替换、面的 GeometryKey 改变时须重新选择，不按旧面号重绑。文档名称/描述补偿与 live 摘要在同一 CAS 事务完成，历史查看不重命名 live 文档。

实例属性的信息页提供“加载最新属性（保留修改）”，用于重新取得属性基线并保留本次已编辑字段；其他对象的属性不显示此操作。它不自动接受被引用零件的新版本。其他对象发生并发保存冲突后关闭并重新打开属性，CAS 不被绕过。

## 全局选项

一个左侧分类、右侧内容的对话框；地面、网格、阴影和主光方向直接排列。每次合法修改立即应用并保存，包括恢复当前页默认设置；关闭不回退。颜色等非法中间输入保留在字段，不覆盖已接受设置。切换文档和刷新复用同一全局设置，不存在文档级场景覆盖。旧 UI preferences 升级保留导航、捕获和单位等既有偏好，场景使用新的全局默认，不从某个文档任意挑选旧设置。

| 分类 | 当前设置 |
|---|---|
| 场景 | 透视/平行投影；深蓝/明亮/石墨配色；上下渐变/纯色；地面位置、网格、阴影；光照预设及方向 |
| 显示 | 正常/线框、边线、交点、基准面/轴/坐标系、草图网格 |
| 新建对象 | 新建零件实体表面颜色、粗糙度、金属度 |
| 导航与捕获 | occccad/CATIA/SOLIDWORKS 手势、旋转球、捕获角色与预设 |
| 单位 | 全局默认显示/新建输入单位；保留明确标注的当前文档显示单位覆盖 |

`app.options` 是全局 UI Command；场景和导航设置不产生模型 Revision、不进入模型 Undo/Redo。当前存储是浏览器本地设置，不承诺账号跨设备同步或项目级共享场景。主页和工作台共用可拖动 CommandDialog、位置恢复及边界限制，Select/ColorPicker 子弹层位于面板上方。

### 场景与显示规则

默认透视投影，ISO 仍使用 `(1,-1,1)` 朝向；近大远小来自投影而非旋转角度。“场景 → 背景 → 投影方式”使用“透视／平行”选择，切换立即生效并保存。切换保持朝向、屏幕关注点及其深度处比例，所有文档共用设置；草图正对、退出与文档相机恢复都支持两种投影。透视 Fit 覆盖全部包围盒角点，透视裁剪只改变 near/far，不沿视线移动相机；动画与相机状态仍不写模型 Revision。35° 是本软件默认值，不宣称是 CATIA 所有版本的固定参数。

渐变固定于屏幕上下端点，纯色使用同一颜色；不随旋转、缩放或平移混入其他色调。地面、草图网格及草图几何/构造/外部引用/求解状态/尺寸/预览共用背景对比规则，选择明暗语义配色；用户实体颜色不参与此转换。网格自动按背景明暗选择线色，主线在宽度与强度上高于细线，地面网格支持手动颜色/强度，草图的语义配色随背景统一切换；地面默认 10 mm 固定基准间距，用户可修改；独立世界网格遵循同一基准。基准线与十倍主线保持世界坐标，极近时补充十进制细分线、极远时补充十进制粗级线，按屏幕尺度连续淡入；每一级都锚定同一文档原点，显示细分不参与草图捕获。每级相位在 CPU 重定位后计算，避免大坐标和近看细分丢失精度。草图网格与捕获继续共用自适应间距。辅助网格只用于观看，草图捕获与网格显示独立。

地面在当前视口首次取得该文档的非空、可见权威实体或草图范围时初始化。初始高度取 minZ 减去尺度适配间隙：`clamp(0.08∛(dx·dy·dz),0.005m,0.08m)`，`m` 为中间有效尺寸，再加用户偏移。尺寸文字、约束图标、临时/历史制品不参与初始化。之后创建、移动、隐藏或删除对象均不重定位地面；空文档等待首次几何，已经初始化的文档清空后仍保留观看平面。重新打开/切换文档会重新初始化，此位置是视图状态，不写建模 Revision。“重新贴合模型”显式按当前范围设置指定高度；世界模式固定 Z=0，指定/锁定高度为全局绝对高度。

地面为世界原点居中的大正方形，首次尺寸由 `10^ceil(log10(max(10000,1000·spacing,4·reach)))` 确定半边长（毫米），`reach` 为包围盒坐标绝对值上限。中心和尺寸随后不随模型范围、网格间距或相机改变。固定细线/主线仍锚定文档坐标；超出观看平面范围不绘制。该范围不参与 Fit、拾取或实体 near/far。网格在实体裁剪范围外饱和深度，保留上下观察的遮挡关系；完全侧视、背向、处于平面内或用户关闭时可以不可见。草图编辑隐藏地面、世界网格和阴影，草图自身网格/捕捉规则保持独立。具体算法见[导航实现](../../../web/apps/cad/src/cad/navigation/README.md)。

光照复用已有程序环境与四盏灯，默认启用零件与地面阴影。不透明实体投射并接收主方向光阴影，透明实体不投射不透明阴影。关闭地面不关闭零件间阴影；关闭阴影则不执行阴影贴图绘制。主光的目标与阴影相机按当前显示构型更新，覆盖范围与地面位置独立；使用 2048² PCF 阴影、统一强度及尺度适配偏移。尚无透明阴影、接触阴影/AO、图片/HDR 导入、物理折射、倾斜地面或共享视图预设；大范围模型的阴影细节受贴图分辨率限制。

### 新建默认值是创建快照

`creationDefaults.solid` 是可扩展的新建对象类别，当前只交付实体；后续曲面等类别应在此处独立扩展，不增加零散入口。普通新建 Part 和 Product 中新建 Part 均在创建请求携带 `defaultAppearance`；服务端验证为整体 `SurfaceStyle`，固化到新 Part 的首个 Revision，与初始事务一起保存。

后续新建 Body/特征继承其所属 Part 的默认外观。改变全局新建默认值不会重染现有文档、导入模型、复制件或共享实例；Product 本身不注入零件实体默认值，避免覆盖引用 Part 的外观。修改已存在文档的默认值应使用对象“属性”。

## CATIA 参考与源码

本机 B33 文档根：`/mnt/c/UserApp/3D/DS/Dassault Systemes/B33doc/English/`。先从 `control/BasEnglishC2.viewdoc` 定位，具体页：

- `online/basug_C2/basugwd0100.htm`、`basugcu0200.htm`：Tools → Options 统一设置分类；`online/basil_C2/basilAboutSettings.htm` 区分临时与永久设置。
- `online/basug_C2/basugbt0602.htm`：单选 `xxx object` 与多选 `Selected objects` 的对象命令组织。当前只放已实现操作，并按用户要求不提供视区右键菜单；不是逐项复制 CATIA。
- `online/basug_C2/basugbt0706.htm`：对象 Graphic 属性；`online/pstug_C2/pstugbt0307.htm`、`pstugbt0341.htm`：实例与定义区分及继承。
- `online/basug_C2/basugbt1305.htm`：初始地面在模型底部、允许移动；不能据此声称 CATIA 每帧贴底。本项目采用首次初始化和显式重新贴合，未复刻 CATIA 的地面拖动手柄。
- `online/bascugen_C2/bascugeneral0100.htm`：P3 是沉浸式界面风格，不是地面网格算法名称。
- `online/rt1ug_C2/rt1ugbt0302.htm`：方向光、地面/环境实时阴影与环境面；零件间阴影采用本项目 Three.js 实现，不据该页推断 CATIA 内部算法。
