# 对象属性与全局选项

对象数据用树右键“属性…”或 `Alt+Enter`，应用设置用顶部齿轮图标（提示“全局选项”，无按钮文字）。对象属性写 Revision；全局选项保存于当前浏览器，作用于所有文档。外观模型和 STEP 边界见[颜色材质](surface-appearance.md)。

## 入口与菜单

- **唯一可见的全局设置入口**是全局标题栏齿轮图标，在文档中心和所有工作台均可用，执行 `app.options`；命令搜索投影同一命令。右下角保留状态、单位/导航提示和当前工具动作。工具自己的“工具选项”与应用设置分开命名。
- **视区右键没有菜单**，原菜单组件、候选列表、事件回调和点击检测均已删除；保留浏览器原生菜单抑制、右键旋转和工具取消行为。选中面后可用 `Alt+Enter` 查看属性。
- **树菜单**按通用操作、显示/隐藏、删除/复制别名、`对象` 子菜单、底部“属性…”分组。定义编辑、工作对象、抑制、引用模式和重连等放在对象子菜单，只投影实际支持的能力。多选只显示可针对选集执行的操作，不把“编辑点击的单个对象”混入批量操作。
- 独立“重命名”“颜色材质”命令、注册和表单入口已移除。名称和外观统一在属性中；机构/关节/驱动/模拟名称复用属性表单，提交仍经既有 `SAVE_KINEMATICS`，不改产品约束。

顶部入口的选择是本软件的取舍：文档中心也需要配置新建默认值，顶部全局位置比仅工作台右下角更一致；无需重复增加“场景属性”按钮或工具栏分类。

## 对象属性

“基本 / 图形 / 信息”固定打开时的目标和基准 Revision。相机与选择变化不切换编辑目标；多选要求同一写入文档和基准版本，混合字段只写实际改动。

| 目标 | 可修改项 | 所有权 |
|---|---|---|
| 根文档 | 名称、描述、默认外观 | 当前 Part/Product |
| Body | 名称、整体与边线外观 | 原始 Part；装配中可仅覆盖当前 occurrence 外观 |
| 面 | 颜色、透明度、粗糙度、金属度、选择性 | 稳定拓扑 anchor；也可为宿主 occurrence 覆盖 |
| 实体 Feature / 草图 | 名称 | 原始 Part，实体图形仍由 Body 管理 |
| 几何图形集 | 名称及独立继承的颜色、线型、线宽、点符号/大小、面外观 | 当前集合及子集合的默认值 |
| 独立几何结果 | 名称及适用于点/曲线/曲面的外观；曲面支持分面覆盖 | 原始 FeatureResult；输入引用不复制外观定义 |
| 用户参考面/线/点 | 名称、颜色、透明度、选择性及适用的线/点样式 | 原始 Part；标准基准面不可改名 |
| 组件实例 | 名称和外观 | 直接实例属当前 Product；嵌套名称为宿主别名 |
| 机构、关节、驱动、模拟 | 名称 | 当前 Product 的机构定义 |

作用范围、写入文档和版本明确显示。Inspector 保持只读；历史/只读上下文不能写入。透明度显示为 0–100%，模型保存 opacity=1−透明度；字段独立继承/自定义，整体修改保留分面属性。

独立对象按“系统角色 → 显式文档图形属性 → 父集合 → 对象”逐字段继承；Part 创建时快照的实体材质默认值仅用于材料外观，不覆盖工程点/曲线/曲面的角色样式。文档属性命令只将实际编辑字段写入 `geometryDefaultAppearance`，与实体默认字段同事务补偿；导入结果的原始整体/分面外观位于用户覆盖之前。恢复继承不会改变其他字段，清除分面覆盖也覆盖导入分面颜色。图形修改不改变 GeometryKey，视区和缩略图共用有效属性；STEP/BREP 的颜色/透明度能力不扩展为线型或点符号交换。组织和删除见[Part 对象生命周期](part-object-lifecycle.md)。

外观通过可取消的防抖 PreviewCommand 返回正式投影，不创建 Revision。确定原子提交，取消清除预览；迟到响应不能覆盖新草稿。冲突保留修改，可重新加载基线；实例删除/替换、面的 GeometryKey 改变时须重新选择，不按旧面号重绑。文档名称/描述补偿与 live 摘要在同一 CAS 事务完成，历史查看不重命名 live 文档。

实例属性的信息页提供“加载最新属性（保留修改）”，用于重新取得属性基线并保留本次已编辑字段；其他对象的属性不显示此操作。它不自动接受被引用零件的新版本。其他对象发生并发保存冲突后关闭并重新打开属性，CAS 不被绕过。

## 全局选项

一个左侧分类、右侧内容的对话框；地面、网格、阴影和主光方向直接排列。每次合法修改立即应用并保存，包括恢复当前页默认设置；关闭不回退。颜色等非法中间输入保留在字段，不覆盖已接受设置。切换文档和刷新复用同一全局设置，不存在文档级场景覆盖。旧 UI preferences 升级保留导航、捕获和单位等既有偏好，场景使用新的全局默认，不从某个文档任意挑选旧设置。

| 分类 | 当前设置 |
|---|---|
| 场景 | 透视/平行投影；中性工程/深色工程预设及自定义配色；上下渐变/纯色；地面位置、网格、阴影；光照、可关闭的轻量 AO 及方向 |
| 显示 | 正常/线框、边线、交点、基准面/轴/坐标系、草图网格 |
| 新建对象 | 新建零件实体表面颜色、粗糙度、金属度 |
| 导航与捕获 | occccad/CATIA/SOLIDWORKS 手势、旋转球、捕获角色与预设 |
| 单位 | 全局默认显示/新建输入单位；保留明确标注的当前文档显示单位覆盖 |

`app.options` 是全局 UI Command；场景和导航设置不产生模型 Revision、不进入模型 Undo/Redo。当前存储是浏览器本地设置，不承诺账号跨设备同步或项目级共享场景。主页和工作台共用可拖动 CommandDialog、位置恢复及边界限制，Select/ColorPicker 子弹层位于面板上方。

### 场景与显示规则

默认采用中性浅灰背景、低金属度缎面和宽柔程序环境高光，保留深色工程预设；预设只修改观看设置，不覆盖现有对象颜色。地面网格和非必要顶点默认关闭，边线默认开启，用户的明确显示选择仍保留。结构树直接叠加在视区上，整列不绘制底板或竖向分隔线；文字按背景明暗切换，选中框只包围节点内容，激活与选择分开表达。属性面板、文字、分隔线及图标线宽共用 visual tokens。原生 DPR 最大为 2。

结构树连接线按真实兄弟关系计算，末项以圆角肘线收尾，仅仍有后续兄弟的祖先列延续竖线；不依赖虚拟滚动窗口是否挂载该兄弟。展开箭头与节点选择使用独立点击区，叶节点不绘制装饰点。箭头旋转、存留行的位置变化使用短过渡；系统要求减少动态效果时关闭过渡。折叠后的选择提示仍只投影到最近可见祖先。设计参考 [Carbon Tree view](https://www.carbondesignsystem.com/building-blocks/core/components/tree-view/guidelines) 的层级、展开与选择分离规则和 [W3C 减少动态效果](https://www.w3.org/WAI/WCAG22/Techniques/css/C39.html)；连接线形态与时长是本软件的呈现选择。

实体拓扑顶点的常态标记默认不绘制，但保留原有精确身份、屏幕拾取范围和对象可见性检查；常态显式显示为 4.5 CSS px 标记，hover／选中分别为 5／6 CSS px 的平面圆点，带细对比边缘；实际圆盘覆盖标记宽度的 80%，不使用草图端点的叉形。显式开启交点显示时可查看所有顶点；隐藏 Body/occurrence 仍会移除其普通拾取。Part 与 Product 的非编辑草图使用低对比颜色、较细线宽和较小点标记，参与深度测试、不写深度，实体可遮挡草图；hover/选中保留语义反馈。进入精确文档、Revision 和 occurrence 的草图编辑后恢复原有点线尺寸、颜色和置顶反馈，退出后重新淡化。显示样式不改变显隐、抑制、求解状态或 Revision。编辑态与非编辑态的视觉区分参考 [SOLIDWORKS 的 Sketch, Inactive 色彩角色](https://help.solidworks.com/2012/english/api/swconst/so_colors.htm)，具体淡化和遮挡策略由本软件定义。

默认透视投影，ISO 仍使用 `(1,-1,1)` 朝向；近大远小来自投影而非旋转角度。“场景 → 背景 → 投影方式”使用“透视／平行”选择，切换立即生效并保存。切换保持朝向、屏幕关注点及其深度处比例，所有文档共用设置；草图正对、退出与文档相机恢复都支持两种投影。透视 Fit 覆盖全部包围盒角点，透视裁剪只改变 near/far，不沿视线移动相机；普通视角以关注／最近已知表面深度的 1% 设置 near，并受正向包围盒最小深度的 10% 上限保护；包围盒接近或跨越眼点且未取得有效表面命中时使用保守回退。动画与相机状态仍不写模型 Revision。35° 是本软件默认值，不宣称是 CATIA 所有版本的固定参数。

渐变固定于屏幕上下端点，纯色使用同一颜色；不随旋转、缩放或平移混入其他色调。地面、草图网格及草图几何/构造/外部引用/求解状态/尺寸/预览共用背景对比规则，选择明暗语义配色；用户实体颜色不参与此转换。网格自动按背景明暗选择线色，主线在宽度与强度上高于细线，地面网格支持手动颜色/强度，草图的语义配色随背景统一切换；地面网格开启后使用低对比颜色，并按世界距离在远处淡出，不影响草图网格。地面默认 10 mm 固定基准间距，用户可修改；独立世界网格遵循同一基准。基准线与十倍主线保持世界坐标，极近时补充十进制细分线、极远时补充十进制粗级线，按屏幕尺度连续淡入；每一级都锚定同一文档原点，显示细分不参与草图捕获。每级相位在 CPU 重定位后计算，避免大坐标和近看细分丢失精度。草图网格与捕获继续共用自适应间距。辅助网格只用于观看，草图捕获与网格显示独立。

地面在当前视口首次取得该文档的非空、可见权威实体或草图范围时初始化。初始高度取 minZ 减去尺度适配间隙：`clamp(0.008∛(dx·dy·dz),0.0005m,0.008m)`，`m` 为中间有效尺寸，再加用户偏移。尺寸文字、约束图标、临时/历史制品不参与初始化。之后创建、移动、隐藏或删除对象均不重定位地面；空文档等待首次几何，已经初始化的文档清空后仍保留观看平面。重新打开/切换文档会重新初始化，此位置是视图状态，不写建模 Revision。“重新贴合模型”显式按当前范围设置指定高度；世界模式固定 Z=0，指定/锁定高度为全局绝对高度。

地面为世界原点居中的大正方形，首次尺寸由 `10^ceil(log10(max(10000,1000·spacing,4·reach)))` 确定半边长（毫米），`reach` 为包围盒坐标绝对值上限。中心和尺寸随后不随模型范围、网格间距或相机改变。固定细线/主线仍锚定文档坐标；超出观看平面范围不绘制。该范围不参与 Fit、拾取或实体 near/far。网格在实体裁剪范围外饱和深度，保留上下观察的遮挡关系；完全侧视、背向、处于平面内或用户关闭时可以不可见。草图编辑隐藏地面、世界网格和阴影，草图自身网格/捕捉规则保持独立。具体算法见[导航实现](../../../web/apps/cad/src/cad/navigation/README.md)。

光照复用已有程序环境与四盏灯，默认启用零件与地面阴影。不透明实体投射并接收主方向光阴影，透明实体不投射不透明阴影。关闭地面不关闭零件间阴影；关闭阴影则不执行阴影贴图绘制。主光的目标与阴影相机按当前显示构型更新，覆盖范围与地面位置独立；阴影接收面与固定的大网格独立：按当前可见实体沿主光方向投影到既定地面，只取地面以上的部分，加上过滤／偏移余量并向外量化到阴影 texel 网格。其高度固定，水平范围只随显示几何或光照定义变化，旋转相机不重定位；全部实体低于地面时隐藏接收面而保留零件间阴影。接收面不参与 Fit、拾取或近远裁剪，避免小模型共用大地面三角形造成遮挡闪烁。使用 2048² PCF 阴影、3 texel 过滤半径、统一强度及尺度适配偏移；缩小初始化离地间隙，使接合区域更易辨认。尚无透明阴影、独立接触阴影 pass、图片/HDR 导入、物理折射、倾斜地面或共享视图预设；大范围模型的阴影细节受贴图分辨率限制。

实体拓扑边默认使用 1.35 CSS px，局部法线证据、连续权重、底色混合和独立交互规则由[自然边线](natural-edges.md)维护；默认材质、曲面法线与阴影缓存由[曲面与光照](visual-studio.md)维护。原始拓扑折线继续用于精确选择，不绘制三角网格边。

非草图编辑时，Part／Product 的普通选择和支持元素拾取在同一交互层、同一近距离组内，按实体顶点、实体边、草图点、草图线、草图约束标记、实体面的顺序选择；组的深度范围为关注深度处 5 CSS px 对应的世界距离，不跨越相隔更远的前后候选。命令的类型／文档／Revision／occurrence 过滤先执行，显式选草图的命令仍能取得草图；进入草图编辑保留原有点线与约束优先级。候选组锚定最近命中深度，避免成对距离比较不满足传递性而产生不稳定顺序。拾取域是临时注册信息，不改变精确拓扑或草图实体身份，隐藏所属对象仍会移除候选。

移动组件开始拖动（含操纵器枢点拖动）即清除已有预选；拖动及最终姿态确认／提交期间，视区、树和其他覆盖层的预选请求统一归空，保留选中组件的轮廓。结束或取消后，下一次悬浮重新命中当前显示几何，不恢复旧预选对象。

实体 hover／选中保持原有面颜色、透明度与光照，只叠加可见拓扑边、面边界及曲面视向轮廓；面内部的三角剖分线不显示，普通边线关闭时仍可显示高亮。实体／实例选择覆盖其精确上下文内的 Body；Feature 仍只覆盖当前贡献的 Face/Edge 集合。轮廓使用 CSS 屏幕线宽、深度遮挡和切割平面；边线使用半像素斜率余量及有界深度偏移，避免自身表面的深度舍入截断笔画，不再使用穿透实体的面填色。点、草图及参考元素保留各自语义反馈。该观看样式参考 CATIA 选中轮廓截图；不推断 CATIA 的内部渲染算法。

多个不透明 Body 共用表面深度代理 pass，将不超过 `16/(2²⁴−1)` 的归一化深度差视为光栅深度平局；再按文档／occurrence／Body／显示阶段组成的稳定显示键确定绘制顺序，避免重合面因材质分配、插入顺序或相机旋转产生交叉条纹。该界限只处理显示深度舍入，不移动几何、焊接面或改变拾取与持久引用，也不能用于判定工程接触。透视下对应的世界距离随视深度及 near/far 变化，极小间隙仍受深度精度限制。单个不透明 Body 不增加代理 pass；多个 Body 的不透明显示增加一次，AO 可复用它；混合透明件时按需另取仅含不透明面的深度，保持玻璃原有排序与不写深度规则。目标纹理随视口调整并在销毁时释放。

轻量 AO 默认关闭，可在光照页开启。它复用已有表面深度代理 pass 的 RGBA 附件存储打包线性视深度，每个不透明实体像素最多 8 次邻域采样，以平面梯度补偿斜面自遮蔽。采样半径为 12 CSS px，强度最高 0.8；这是屏幕空间观看辅助，不能作为间隙、接触或干涉的工程证据。背景不参与 AO；可见透明实体、草图编辑或线框显示时禁用。关闭 AO 本身不增加额外绘制；多个不透明 Body 的重合深度处理仍使用上述代理 pass。相机外遮蔽、透明遮蔽与物理光照不在支持范围。

### 新建默认值是创建快照

`creationDefaults.solid` 是可扩展的新建对象类别，当前只交付实体；后续曲面等类别应在此处独立扩展，不增加零散入口。普通新建 Part 和 Product 中新建 Part 均在创建请求携带 `defaultAppearance`；服务端验证为整体 `SurfaceStyle`，固化到新 Part 的首个 Revision，与初始事务一起保存。

后续新建 Body/特征继承其所属 Part 的默认外观。改变全局新建默认值不会重染现有文档、导入模型、复制件或共享实例；Product 本身不注入零件实体默认值，避免覆盖引用 Part 的外观。修改已存在文档的默认值应使用对象“属性”。

- `online/basug_C2/basugbt0601.htm`：几何与结构树的预选／选择反馈，线型可配置；本项目保留 hover 与选中各自的语义颜色。
- `online/basug_C2/basugbt0602.htm`：单选 `xxx object` 与多选 `Selected objects` 的对象命令组织。当前只放已实现操作，并按用户要求不提供视区右键菜单；不是逐项复制 CATIA。
- `online/basug_C2/basugbt0706.htm`：对象 Graphic 属性；`online/pstug_C2/pstugbt0307.htm`、`pstugbt0341.htm`：实例与定义区分及继承。
- `online/basug_C2/basugbt1305.htm`：初始地面在模型底部、允许移动；不能据此声称 CATIA 每帧贴底。本项目采用首次初始化和显式重新贴合，未复刻 CATIA 的地面拖动手柄。
- `online/bascugen_C2/bascugeneral0100.htm`：P3 是沉浸式界面风格，不是地面网格算法名称。
- `online/rt1ug_C2/rt1ugbt0302.htm`：方向光、地面/环境实时阴影与环境面；零件间阴影采用本项目 Three.js 实现，不据该页推断 CATIA 内部算法。
