# 线框与曲面 Feature

当前交付独立 Part 中的关联曲线、工程曲面构造/编辑、形状控制与只读曲率分析、加厚与封闭成实体、开放及混合几何 STEP/BREP 交换，以及原实体扫掠对正式三维曲线的消费。它们共用 Part Feature 历史、参数、Domain Command、预览及制品管线。操作见[使用指南](../../guides/wireframe-surfaces.md)；阶段与后续范围见[阶段设计](../../../plans/wireframe-surface-design.md)。

源码入口：Workspace `geometric_feature.go`、`geometric_reference.go`、`evaluation_projection.go`、`part_bodies.go`；协议 `geometry_worker.proto`；OCCT `geometry_feature.cpp`、`surface_feature.cpp`、`surface_shape_control.cpp`、`curvature.cpp`；Web `geometric-feature-editor.tsx`、`geometric-input-selection.ts`。先按操作名搜索，不默认展开整个实体 evaluator。

## 所有权、输入与结果

- `GEOMETRY` Feature 和“线框与曲面”标签新建的 Sketch 归 `geometricalSetId`；实体特征归 `bodyId`，两者互斥。普通几何图形集只组织和控制显隐，全 Part DAG 决定依赖，集合顺序不构成材料前驱。首次创建可原子建立默认集合；既有草图不隐式搬移。
- `features[].result = {id, domain, geometryKey}` 是派生引用，正式输出角色为 `result`；`POINT_SET / WIRE_SET / SHEET_SET` 独立于 Body；导入混合内容保留为 `MIXED_SET`。`THICKEN / CLOSE_SURFACE` 是原 Body 管线中的实体生成器，仍接纳非空有效 Solid 集，支持新 Body、添加、切除及交集的领域操作。
- 输入分别为固定 Sketch entity ID 集、整个动态 `FeatureId + ResultId` 结果、固定拓扑 `PersistentSelection` 或显式 DatumPlane。`sourceBodyId` 与 `sourceResult` 恰有一个，拓扑绑定记录来源 Revision/Feature 和证据；不能保存 localId、数组位置、显示名或屏幕坐标作为身份。
- 构造点可引用参考点、草图的稳定点/端点/圆心或正式点结果/顶点；方向可引用参考轴、坐标系轴、草图直线、精确直线边或平面法向。旋转轴另带来源原点，镜像及圆/圆弧支撑引用平面。所有引用进入原 DAG、删除保护及上游顺序检查。
- 控制点拥有稳定 ID；插点不挪用其他点的权重槽，替换来源保留本地点 ID。UI 只编辑半径、长度、角度、弧长比例及权重等量值/表达式，不创建独立坐标或向量参数。领域 API 仍可显式定义坐标曲线和数值框架；引用方式不为已关联方向额外建立 XYZ 槽。二维 PlaneGCS 不承担三维约束求解。

Worker 只接收冻结精确 BREP/Naming、规范曲线或显式平面；来源的 owner、阶段、BREP digest 和完整 Naming 必须一致。构造使用真实 Generated/Modified/continuation 和稳定构造角色，再做严格拓扑邻接闭包；相同稳定来源仍无法消歧则失败，不能按位置补名。

## 已实现范围

| 操作 | 当前语义与限制 |
|---|---|
| 直线、圆、圆弧 | 有限精确曲线；UI 选择端点，圆/圆弧选择圆心和支撑平面，设置半径/起止角；圆心须位于支撑上 |
| 三维样条 | 插值点或控制点方式；控制点次数、规范节点/重数和正有理权重；空点列起步，逐点拾取，支持插前/插后、替换、移除及权重，不提供任意三维约束求解器 |
| 曲线上点 | 单条有限边的归一化弧长比例；不是原生曲线参数 |
| 提取、边界 | 固定精确边/面或整个结果；边界提取自由边，周期缝和合法退化边不算自由边 |
| 组合曲线 | 精确成员组成连通无分叉 Wire，保留方向；不重拟合、不自动跨接断口 |
| 投影、交线 | 沿关联方向投影到选定有限面或无限基准平面；有限面之间或面与平面求交。不同稳定来源对可产生多个成员；同一来源对的多支路不能稳定区分时明确拒绝；相切点/重合域尚无独立结果语义 |
| 平面曲线偏移 | 关联基准面或精确平面面片、精确平面性检查及有符号距离；当前支持实现可判定的线、圆/椭圆及样条，不承诺任意空间法向偏移。正号沿输入方向的左侧，逆时针圆正偏移缩小半径 |
| G1 连接 | 第一曲线终点到第二曲线起点的三次 Bezier，方向与正切线尺度显式；不承诺 G2 或任意支撑匹配 |
| 分割、修剪、延伸 | 分割/修剪按单边归一化弧长点或保留区间；延伸限直线/圆的起端、末端或两端，圆不超过一周。尚非通用切割对象/点击保留区域式编辑 |
| 平移、旋转、镜像 | 选择对象后选择方向/旋转轴/镜像平面，调整距离或角度；保留关联框架和真实变换历史 |
| 拉伸曲面 | 固定草图曲线或正式有限 Wire 沿关联直线、参考轴或平面法向及长度产生侧面；开放或闭合轮廓均不自动封盖、不参与材料布尔 |
| 加厚 | 有界 Sheet 的有符号常厚度生成有效 Solid，再进入原 Body 操作与修改链；单面采用简单偏移，多面采用求交连接及封边，保存真实历史；自交、退化、开放壳或厚度失败拒绝 |
| 曲面扫掠 | 显式截面和单条 G1 路径，检查各边连接及样条内部的单侧切线；截面须在路径起点法平面内，修正标架/曲率标架可选。保持实际路径×截面生成历史，不自动移动截面或平滑尖角 |
| 曲面放样 | 2–32 个有序开放/闭合截面，开闭状态及边数须一致；逐截面反向/重排，平滑或直纹。支持显式闭合点、内部点对应及可选 spine/站位点，不自动选择对应点；详见下节 |
| 填充 | 无支撑时为连通闭合 G0 边界，最多 256 段，检查算法 G0 误差；有支撑时为四条有序单边的受限导数构造 |
| Boundary / Blend | 边界曲面为四条有序单边，桥接曲面为两条同向单边；逐边选择 G0/G1/G2、支撑和参数化张力，接纳范围见下节 |
| 曲率分析 | 冻结 Revision 的曲线/面片/独立结果；精确 BREP 导数计算曲率梳、主曲率/均值/高斯曲率采样点；只读，不保存分析或写 Revision |
| 裁剪曲面 | 源曲面、有限切割曲面或基准平面、关联保留点；保留点必须位于唯一面片内部，由真实交线隔开的连通区域确定保留部分。未相交、点在边界或不在源面上明确失败；不隐式外推 |
| 延长曲面 | 单面矩形参数域，选择该源面自身的等参数自由边界及物理长度；G1 外推并保留源域。一般修剪面、孔、非等参数边及周期缝拒绝，不丢弃原修剪边界 |
| 连接、缝合 | 显式成员及连接容差；连接验证连续/流形后组织原面片，缝合建立共享边界的 Shell。连接不等同于已缝合；封闭前使用缝合。断开、多重边、自交拒绝 |
| 偏移曲面 | 有限曲面集的有符号常量偏移及真实修改历史；失败不删除子面、不自动平滑或放大容差 |
| 封闭曲面 | 单个已缝合闭合壳，检查自由边、流形、内外方向、自交及正体积后进入原 Body 管线；不自动补盖。支持新实体、添加、切除及交集 |
| 原实体扫掠 | 新增正式三维边/连通 G1 Wire 路径，精确冻结输入；截面起点和法向需匹配路径，曲率标架/修正标架可选。空间尖角拒绝，既有平面草图直线斜接另保留 |

## 形状控制与连续性接纳

`surface` 的 spine、guide、section/boundary controls 均保留正式几何引用。每个截面/边界控制拥有 UUID，并引用原输入；对应组也有稳定 UUID，张力参数槽为 `geometry:tension:<controlId>`。重排/反向不迁移控制到别的行；移除输入会移除其控制。点、导向、spine、支撑进入原 DAG、缓存、删除保护、预览/提交及 Undo/Redo。Worker 的 `section_index / boundary_index` 仅定位本次冻结数组，持久模型不保存它们。

- **Spine / 导向**：普通扫掠保留原 G1 Wire 路径；增加导向或使用 spine 放样时，首版限单条开放 G1 边。Spine 放样必须逐截面拾取站位点，点唯一位于 spine、按截面顺序排列，首末站位在两端，截面完整位于相应法平面。不自动平移、投影截面或外推。导向方式显式区分 `GUIDE_FRAME`（姿态）与 `GUIDE_BORDER`（贴合边界）。姿态模式限单条开放 G1 边，须通过每个开放截面的一个端点，控制标架，**不保证中间区段贴合导向边界**。贴合边界模式限直线 spine、单边直线截面与非有理多项式导向；截面从 spine 指向对应导向点。通过导向全部极点的正交投影构造 spine 边及精确直纹曲面，导向本身就是整条另一边界；Bernstein 导数系数确认沿 spine 严格前进，径向凸包确认不穿过 spine，未确认即拒绝。放样各截面按关联站位逐一验证，贴合边界暂不叠加闭合点/内部点对应。不混同 CATIA 的一般截面边界接触、双导向、法则或自动 spine。
- **闭合点与点对应**：多边闭合截面选择已有连接顶点；单边完整周期曲线可选曲线内部闭合点。内部点对应限单边截面，每组覆盖全部截面，最多 16 组，按各截面的方向严格排序。精确投影只验证已声明点的所属和参数，不用最近几何恢复身份。对应点分割出带稳定构造角色的区间，再交给放样；错误顺序/多重投影/缺失组失败。
- **Boundary / Blend / 带支撑 Fill**：当前限开放、有限、非有理的多项式边界，次数不超过 12、单输入至多 128 极点，公共基底和张量网另有预算。Boundary/带支撑 Fill 接受四条依次闭合的单边；Blend 接受两条同向单边。G1/G2 支撑为原边所属的单个矩形参数域曲面的等参数自由边，曲面转为非有理 B-spline 后提取完整边界导数；周期缝、一般修剪边和有理支撑拒绝。也可选显式基准平面，首版限单段多项式边界。边界自身须满足所需连续阶次。
- **连续性构造与验证**：Blend 使用横向五次 Hermite；Boundary 使用张量 Hermite-Coons，逐边构造位置/一阶/二阶导数。G1 匹配支撑一阶边界导数，G2 再匹配二阶导数，允许显式张力对应的线性参数缩放；支撑侧反向为显式输入，不由上游几何改变时自动猜测。角点混合导数不兼容时拒绝，不放松约束。输出全边导数系数残差以归一化参数域中的 mm 检查，阈值为工程容差；每个 Bezier 区间的边界法向用 Bernstein 凸包及有界细分确认非零，未确认/超预算失败。最后检查 BREP 有效性及自交。此为受限构造与数值残差策略，未承诺任意参数化下的全局角度/曲率误差上界；不以采样法线或显示颜色替代该检查。

### 只读曲率分析

`POST /api/documents/{id}/shape-quality` 接受 `revisionId`、正式 `GeometricInput` 和 16–4096 的采样预算；仅独立 Part，选择精确边/面或整个几何结果，不消费草图显示折线。绑定/解析仍校验 owner、来源 Revision、Naming 与证据，Worker 复用正式 Router 的 `MeasureGeometry(kind=CURVATURE)`，只消费冻结 BREP。请求前后校验 Head，超时/取消及旧响应不能显示到新 Revision，不写 Domain Command 或持久测量。

曲线在各 C2 区间按弧长取内部采样，内部 C2 断点不提供两侧合一曲率；曲面在有限 UV 域采样并排除修剪孔/外域。导数来自精确几何，曲率单位为 `1/mm`，高斯曲率为 `1/mm²`，反向面同步反转法向及有符号主曲率。上限为 16 个面、64 条曲线和 8192 个显示样本；奇异/未定义位置计数，不能伪装为零曲率。界面显示**采样最小/最大值**、有效数量与未定义数量；曲率梳长度是可调显示比例，曲面为彩色采样点，不是完整连续热力图，不证明极值或 G2。关闭、切换上下文或 Revision 改变时释放临时图形。

## 交互与求值

“实体”和“线框与曲面”是同一 Part Design 工作台的并列 toolbar tab；切换不生成 Revision。草图仍有独立上下文；测量、参数与接口、视图和文档功能保持公共分类。

曲线/曲面及参考元素创建不复制命令前的选中对象，不填充示例曲线或默认支撑；必需的几何字段为空时不发预览、不能确认。输入按角色依次激活，在视图区或结构树拾取，连续点列按点击顺序绑定；切换字段、退出会话和 Revision 改变使未完成的绑定失效。参考点计入视图适配；固定屏幕尺寸的平面/轴图标不扩大适配范围。

创建与编辑共用紧凑拾取字段、数量/表达式和全局错误反馈，不使用来源下拉列表或“更多”折叠区；点列可定位已选点。命名沿用树的统一改名，容器沿用上下文/默认集合。

预览与提交走同一权威 evaluator；预览不写 Head，确认绑定 actor、Revision、payload 和 preview token，提交继续 CAS 与幂等。方向、支撑和点的引用在冻结模型内解析为 Worker 数值输入；缓存同时记录正式引用、解析框架及 BREP/Naming 来源快照。上游参数改变重建消费者；自身无效编辑拒绝，已有下游失效按原失败/阻塞合同呈现，用户可重选输入。Undo/Redo 使用 ChangeSet 补偿和重放。独立几何与集合均可单独显隐；显隐、改名等组织动作不改变几何身份或触发几何重建。

每项独立结果拥有 BREP / GLB / Naming，下载授权按冻结 Revision 的 Body 或 FeatureResult 引用检查。GLB 可只有线/点，不制造空面或假三角形；工程曲线使用随明暗背景调整的紫色和屏幕固定线宽，工程点/参考点使用带深色描边的白色叉号，与草图点及实体顶点区分；开放面采用哑光蓝灰色、双面光照和阴影，并避让共面显示深度；仅曲面场景也建立阴影范围。缩略图收集可见独立结果、真实线/点和参考点，继承集合显隐，不依赖实体三角形。曲线/点独立命中。独立结果的树悬停/选中按同一 Revision、结果所有者及 GeometryKey 高亮整个结果；实体历史特征仍按真实当前贡献高亮。属性区分别显示特征操作、结果域及精确面/边类型。`geometryDomain` 决定物理量是否适用：开放结果的内部 `volume=0` 只是存储占位，不能作为实体体积或质量展示。格式与门禁分别见[制品](geometry-representations.md)、[Naming](persistent-naming.md)。

## 开放几何交换

STEP/BREP 导出冻结同一 Revision 的有效 Body 与可见独立 FeatureResult，分别携带 BREP 引用；不制造 Body、不用显示网格替代精确几何。STEP 保留原 Part/Product 交换图，BREP 为形状交换；默认排除源集合隐藏的独立结果；可选择包含隐藏对象，不删除模型依赖。具体选项及格式边界见[导入与导出](exchange.md)。

导入在精确规范快照上分配首次注册的稳定 Face/Edge/Vertex 身份，绑定 BREP SHA、OCCT 版本和命名策略；重新导入是新身份根。纯 Solid 继续进入 `IMPORT_BODY`。开放或混合内容进入几何图形集中的只读 `GEOMETRY / IMPORTED` 定义，其命名种子以 `resultId` 为所有者，不能通过普通创建/编辑命令伪造。后续可通过正式拓扑选择消费；原导入根不可修改，仍可隐藏或删除。

混合输入完整保存在一个 `MIXED_SET` 中，当前不自动分拆为可编辑材料 Body；需要材料历史时使用独立实体来源，或提取面并缝合/封闭。开放输入不隐式修补、缝合或封闭；不能进入有效 BREP/Naming 的可读取 Definition 创建空 Part 并警告。Body 与独立结果均承接导入整体/分面 RGB 和透明度；参数历史不随 STEP/BREP 传递。`MIXED_SET` 的体积存储值同样不作为材料体积。

## 验证入口与未交付边界

Part 和 Product occurrence 已接入独立结果显示及交换；READY ContextVariant 的独立结果求值、Publication/跨零件消费及完整测量仍待扩展。Surface Revolve、一般曲面 Split/互裁、Up-to 外推、双/多导向、一般截面的边界接触/法则、自动 spine、一般支撑 G1/G2、有理高阶补面、复杂偏移修补均在后续范围。法向/自由边专用叠加、UV 等参数线、斑马纹、有序集合及吸收显示未交付；源几何按集合可见性保留。拓扑历史无法唯一命名时拒绝，未经工业模型成功率、全局误差界或容量/性能认证。原生算法内部不能保证即时取消，提交前和循环阶段仍检查取消。
