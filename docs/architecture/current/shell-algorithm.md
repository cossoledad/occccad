# 恒定壁厚抽壳算法

抽壳移除所选开口面，对所属 Body 生成恒定厚度的内壁或外壁。长度、方向和开口以 Feature 定义保存；精确 BREP、Naming 和 Visual 由权威求值重建。通用 Feature 合同见[实体 Feature](solid-features.md)。

## 输入与执行边界

- 开口使用 `PersistentSelection`，在当前 Feature 的上游 Body 阶段解析；缺失、歧义或类型变化明确失败，不按坐标或面序号重新绑定。
- 厚度必须为有限正数，单位为文档建模单位。向内或向外是显式分支，不用缩放截面模拟厚度。
- 每条构造路径操作独立副本；源 Revision、上游 BREP 和已接受分支保持不可变。

## 构造路径

1. **凸全平面实体的向内抽壳**：对保留面建立精确偏置半空间，求交得到内腔，再从原实体扣除。允许小倒角面在偏置后消失；内腔为空或未减少材料时拒绝。
2. **通用偏置**：使用 OCCT 厚实体偏置，依次尝试面求交和圆弧连接，适用于向内、向外。仅接受通过后续门禁的候选。
3. **开口光滑壳偏置**：向内抽壳可从移除开口后的光滑壳构造厚度。
4. **独立面壁层与一次分区**：各保留面独立生成真实法向厚度层；将全部壁层与原实体交给一个 `BOPAlgo_CellsBuilder` 求交数据集，只取同时位于壁层和原实体内的材料，删除内部材料界面并进行同域合并。启用 OBB 筛选和 Worker 受控并行。
5. **顺序组装补充路径**：对独立壁层逐层与输入求交，再按源顺序做二元并集。使用开口局部框架中的有界旋转及统一尺度调节，厚度与容差同比缩放，逆变换恢复模型单位。

按上述顺序选择首个合格候选；失败路径的候选和历史不进入结果。最后两条补充路径仅用于向内抽壳。

## 凹圆形连接材料

在单 Solid 的完整圆形平面/圆柱凹交界，两个面的法向壁层还需要圆边到内壁的过渡材料。通过真实边面邻接、解析轴线、圆半径及材料侧分类识别该交界，排除开口、凸边及不合格几何。

以源圆边为中心，在圆柱外侧、保留材料的轴向象限构造半径等于壁厚的四分之一圆扇区，再绕源圆轴旋转。该连接体与全部壁层及原实体共用一次分区，最终材料仍被原实体裁剪。只构造所需象限，厚度小于、等于或大于孔半径时均不需要自交环面。

生成面以源边的真实 `Generated` 关系加入历史；复制、偏置、裁剪、分区、组装、同域合并和逆变换合成一条完整 Naming 链。边面对应不来自几何邻近猜测。

## 精度与结果门禁

精度预算为 `max(1e-5 mm, 输入最大边/点容差 × 1.01)`。检查精确实体有效性、连通性、3D 曲线/pcurve 一致性及端点偏差。若只有保守记录超限、实际几何偏差仍合格，可在独立副本中收紧记录；不提高预算或移动支撑曲线/曲面。

纯 `INTERNAL` 边用途的辅助线框被清除，真实材料轮廓、孔洞及实际删除历史保留。需要局部端点闭合时，采用原曲线上的有界参数投影及最小包围球代表点，并重新检查实际误差。顺序组装还检查自干涉、保留面后的材料覆盖、序列化重读与线框排序。

向内结果必须减少材料且包含于原实体。一次分区直接与输入求交、且未重定位端点的结果可复用构造包含证明；其他候选执行独立包含性检查。结果必须提供完整 Face/Edge/Vertex Naming 和可消费的逐面显示网格。显示重试使用公开网格扩展点保留源边界三维采样，仍执行全部警告、覆盖和共享边界门禁，不修改精确 BREP。

失败分别报告过大厚度、偏置失败、断开的壁层、精度超限、自干涉或显示失败；不能通过丢弃材料、放宽公差或采用旧预览获得成功。

## 性能与限制

一次分区复用偏置曲面交线，避免先合并再裁剪的重复求交。凹圆形连接体直接进入同一分区，避免因缺失连接材料而进入多次无效组装。日志记录 `wall_offsets`、`wall_partition`、`wall_assembly`；这些阶段包含于精确求值耗时，不能相加到总耗时之外。已采用的预览和运行时缓存耗时与冷计算分开测量。

本算法不保证任意曲面、任意厚度或所有凹边均可抽壳。解析连接体限完整圆形平面/圆柱交界；多角交会、一般凹曲边及复杂向外偏置仍受通用 OCCT 能力限制。曲面求交仍是复杂输入的主要成本。

## 实现与验证入口

- `kernel/occt/src/occt_kernel.cpp`：路径调度、壁层分区、历史、精度及结果门禁。
- `kernel/occt/src/shell_corner.cpp`：解析凹圆形连接体。
- `kernel/occt/src/shell_junction.cpp`、`mesh_boundary.cpp`：受控端点闭合与显示边界采样。
- `kernel/occt/tests/geometry_exchange_scenarios.cpp` 的 `Shell*`：平面、放样、圆角后抽壳、倾斜盲孔、厚度跨越孔半径、材料分类、完整 Naming、网格及上游不可变。
- `services/internal/geometry/shell_worker_integration_test.go`：真实 Worker 与制品；`web/apps/cad/browser/solid-feature-live.spec.ts`：真实预览、提交、编辑、失败恢复和重开。

执行入口为 `invoke check --scope geometry --match Shell`；测试范围与实际结果另行记录，不将测试存在视为验收通过。
