# 简单接合、驱动坐标与固联交互扩展设计

> 本文定义简单接合、驱动坐标与验收矩阵；已实现的基础范围及限制以[当前机构合同](../current/kinematics-dmu.md)为准，矩阵条目不代表执行通过。长期流程沿用[机构与 DMU 主方案](kinematics-dmu.md)，参考来源见[工作流来源](../../references/cad-workflows.md#五类简单接合与固联组)。

## 范围与已经确认的事实

当前基础范围范围覆盖棱形、圆柱、平面、刚性、球面五类接合的创建、编辑、移动、结构树、求解见证、混合机构模拟和产品转换，同时补齐产品固联组以三维选择为核心的操作体验。棱形为 Prismatic，机械语义是移动副，本文及 UI 沿用维护者指定的“棱形接合”名称。

范围继续为根 owning Product、刚性 Instance 和单机械装置。圆柱接合允许角度与长度两个命令，机械装置内允许选择完整的独立驱动集合。多机械装置同步、可动嵌套、动力学、连续碰撞、齿轮／螺旋等耦合接合不在当前基础范围范围内。已有旋转接合须通过同一新坐标合同，不保留一套特殊录制流程。


## 共同决策

1. Joint 定义物理运动关系；Command 定义某个可驱动坐标；Simulation 记录合格状态对应的完整命令向量。任何类型都经过现有装配求解器。
2. 接合单独具有的自由度是局部运动语义，机构自由度由全部关系、Ground 与独立 Jacobian 秩决定。不能按接合数、驱动复选框数或表中自由度相加减。
3. 命令仍在接合对话框中勾选生成，不增加独立创建命令或运动规律入口。选用一个已有命令与创建一个命令是两种不同操作。
4. 每个标量坐标的限位只保存一份，位于所属 Joint。驱动坐标上下限必须均启用，未驱动的同类坐标允许单侧、双侧或无限位。
5. 平面与球面按所核对的基础流程作为被动接合，不提供任意 X/Y/欧拉角驱动。它们可以参与由其他接合驱动的混合机构；单独创建不保证具备命令模拟资格。
6. 刚性接合保持两个 Instance 的相对位姿；Ground 保持一个 Instance 的空间位姿。刚性关系不会自行把组件固定在世界中。
7. 产品固联与机构刚性关系分别拥有身份、约束和捕获基准。两者复用固联定义与相对刚性编译基础，产品内的可变组更新流程不能在机构试动中重新捕获刚性关系。
8. 求解 nominal、冻结环境与显示 View 分离。播放、时间定位和退出交接都使用完整帧，验收必须检查内部实体的世界矩阵。

## 接合与真实装配关系

下表的独立秩以一个端固定、另一端可动且几何非退化为前提；“一条约束对象”可以包含多条数值方程。列出的对象数量是持久业务关系数量。

| 接合 | 三维输入 | 持久机构约束 | 独立秩／剩余自由度 | 可创建的命令 |
|---|---|---|---|---|
| 旋转 Revolute（既有） | 两轴、两轴向定位平面 | 轴重合＋轴向偏移 | 5／1：绕轴转动 | 角度 |
| 棱形 Prismatic | 两轴、两转角定位平面 | 轴重合＋绕所选轴的定位角 | 5／1：沿轴平移 | 长度 |
| 圆柱 Cylindrical | 两轴 | 轴重合 | 4／2：沿轴平移、绕轴转动 | 长度、角度，分别勾选 |
| 平面 Planar | 两平面 | 平面重合；非零定位偏移时为有向平面偏移 | 3／3：面内两平移、绕法向转动 | 当前基础范围无 |
| 刚性 Rigid | 两 Instance | 一个两成员固联组定义，编译为相对刚性关系 | 6／0：无相对运动 | 无 |
| 球面 Spherical | 两点或精确球心 | 点重合 | 3／3：绕公共点的空间转动 | 当前基础范围无 |

既有真实约束仍使用普通名称、编号、图标、选择、高亮及 Quantity 规则。生成数量不再固定为“两条”：圆柱和平面、球面、刚性都只有一个基础关系对象。禁止通过额外隐藏 Fix 或角锁把自由度压成现有单角模型能够处理的数目。

## 棱形接合

### 几何和坐标

两轴重合限制两项横向位置和两项倾斜；两定位平面确定余下的绕轴朝向，沿轴距离保持自由。两定位平面属于各自端点 Instance，作用是转角定位，不是旋转接合中的轴向定位平面。

采用两平面法向在公共轴垂直平面内的投影，建立有向定位角。持久约束复用带正式参考轴的 ANGLE，不能使用没有参考轴的空间夹角。参考轴来自第一端稳定轴支持。任何定位法向与其轴平行、投影过短或支持不完整时，返回“定位平面方向无效”；不猜另一条世界轴。

定位角默认 0°，可明确设置其他角度。此量是 Joint 的静态几何参数，不创建角度命令，也不成为时间目标。该投影角方案是本项目对转角定位的明确语义，CATIA 创建页只确认两线两面的输入，不能据此推断其内部残差。

两端坐标原点 O_A/O_B 均为持久捕获的 body-local 点，z_A 为第一端正轴。长度坐标为：

~~~text
q_length(X) = direction_length · [z_A(X) · (O_B(X) − O_A(X)) − zero_length]
u_length = q_length − reference_length
~~~

zero_length 在接合首次通过完整定义求解的位置捕获并保持不变，使该定义位置为坐标 0；命令 Reference 是独立的操作读数原点。长度有符号，不使用两无限轴之间的最短距离：重合轴的线线距离永远为零，无法表达行程。改变轴向正方向不会倒转几何轴重合关系；这两个方向字段须分开。

### 对话框和操作

使用标准 M 宽度及确定／取消。按“轴线重合”“转角定位”分组，提供第一／第二轴线、第一／第二定位平面、定位角度 °、“长度驱动”和“接合限制”。限制包含长度正方向、上下限启用框及 mm 输入。

拾取沿用现有角色推进、预选、清除和精确检查。两轴齐全可预览圆柱式的不完整关系；必须补齐两定位平面并通过完整求解才可确定。清除或替换支持立即撤销旧预览资格。

勾选长度驱动后显示当前命令读数基准的上下限。缺失限位端提供 −100/+100 mm 的显示默认值；已有端保持。默认范围不是几何可达性承诺，当前构型必须落在有效范围内。

## 圆柱接合

### 几何和坐标

只要求两个轴支持，不要求两定位平面，也不生成轴向偏移。轴支持沿用精确基准轴、直边、圆柱轴、圆边法向轴和圆锥轴的解析规则。

该 Joint 同时拥有稳定的轴向长度坐标和转角坐标。轴向长度沿用棱形公式；转角沿用现有有向轴角及连续展开，但不引用不存在的定位平面。

角度横向基准在接合定义时从两端所属 Part 的局部坐标方向建立，投影到各自轴的垂直平面，并保存 body-local CapturedX。候选局部方向退化时按冻结的确定性策略选择另一局部方向；正式支持如有完整 Frame 则优先使用。不得在每次打开、求解或更新中重新从世界 X 轴构造零位。该捕获只定义读数，没有额外机械约束。

### 对话框和双驱动

对话框只有两轴、轴关系方向、“角度驱动”“长度驱动”及接合限制。角度和长度限制分行显示、分别启用；角度显示 °，长度显示 mm。选中一项驱动只强制该项的两端限位。

两项勾选保存两个不同 ID 的命令，绑定同一 Joint 内不同 Coordinate。取消一项不删除另一项，不重设另一项零位，不改变物理限位。对应命令被模拟引用时禁止取消。

固定一个端、没有其他关系的圆柱副有两个物理自由度。仅创建一个命令可以保存定义和进行普通受约束移动，但不足以建立唯一的命令录制路径；模拟需要两个独立活动命令。若其他接合已消除一项自由度，则一个合适命令可能足够，必须以真实求解资格判定。

## 平面接合

两平面来自不同 Instance，允许基准面或精确平面。基础关系是法向同向／相对且平面重合；可设置固定法向偏移作为本项目扩展，非零时使用现有有向平面 Offset 合同。默认偏移为 0，只有一个真实关系对象，不能同时保存重合与非零偏移。

对话框提供两平面、法向关系、定位偏移 mm、确定／取消。平面法向只负责平面关系，不选择面内 X/Y 方向。没有额外轴或原点定位，不锁定面内转角，不额外限制面内两项平移。

当前基础范围不暴露面内长度／角度命令及其标量限位。两平面本身没有定义用户可识别的完整面内坐标系；若后续需要矩形行程边界或面内驱动，必须增加明确的面内参考 Frame 和坐标合同，不能直接将世界 X/Y 读数放进限制区。这是基础平面副的范围边界，不是把面内自由度省略为零。

普通移动可以在全部活动关系允许的面内运动；参与已由其他命令完整驱动的机构时，位姿从整体求解回算。单独平面副没有命令时，“使用命令进行模拟”和“模拟”不制造隐式驱动。

## 球面接合

基础输入为两个不同 Instance 上的精确点。直接支持稳定命名顶点、基准点／原点、Point Publication；点击球面时自动选择已有正式 derivedRole 的精确球心，并保留源 PersistentSelection/Publication。精确检查须确认是 SPHERE，不能将任意圆弧中心、包围盒中心或鼠标命中点猜作球心。

对话框只提供“第一球心／点”“第二球心／点”、名称、确定／取消。必要时在视图区以球心标记反馈派生点；不要求用户另建点或从 UUID 下拉查找。此语义不要求球与球窝半径相等，不创建接触或碰撞约束。

保存一个点重合关系。独立闭合检查只验证两个点的位置，不要求两局部轴平行，也不要求两端姿态相同；后三项转动保持自由。

当前基础范围不提供三个欧拉角命令或摆角／自转限位。球面接合仅由两点定义，没有唯一的驱动轴和完整方向基准。后续若需要锥形摆角边界、万向式驱动或扭转界限，应单独定义两个参考 Frame、SO(3) 坐标与奇异处理；不能复用旋转接合的单角字段来宣称球铰已经受控。

球面可以作为混合机构中的被动连接。路径连续性同时检查完整刚体转动和已定义的活动坐标，不能靠三个 Euler 数的跳变判断支路。

## 刚性接合与产品固联的捕获边界

### 机构刚性关系

选择两个 Instance，三维面／边／点预选均解析为所属 Instance，并整体高亮。对话框显示两零件，不要求用户选择几何轴面；确认捕获当前合格构型的相对 SE(3)：

~~~text
C_AB = inverse(X_A) · X_B
physical relation: inverse(X_A(t)) · X_B(t) = C_AB
~~~

保存一个两成员 FIX_TOGETHER 约束定义，成员关系是唯一相对基准，Joint 不再另存一份可独立编辑的相对矩阵。数值层复用固联的 groupRigidConstraints 与 RIGID 原语；RIGID 原语不是新增的用户装配约束类型。

两成员关系可在首次定义、显式更换接合端点或明确重定义该刚性接合时捕获。读取、普通移动、命令目标、播放和其他接合的编辑都不能重新捕获。普通编辑只改名称也不能重新捕获。

创建时先取得满足既有机构关系的合格候选，再捕获并验证新增刚性关系。已有相容关系按独立秩处理；不因为方程冗余就删除它们。已有刚性接合与后加关系冲突时拒绝后加候选，不通过更新 C_AB 消除冲突。没有 Ground 的刚性对保留六项整体运动。

### 与普通产品组的差异及复用

产品固联保留现有“组内先解、再作为整体解组外”语义。组成员或组内约束显式改变时允许按合格内部结果更新相对捕获；未改变输入时复用已有捕获，失败不覆盖。

机构 Rigid Joint 把捕获关系作为自身不可漂移的硬定义，编译冻结组时直接消费这些关系。不能调用会因其他内部约束变化而自动重捕获的产品组更新入口。实现中须明确“产品组内部更新”和“机构接合定义捕获”两个拥有者／执行意图，复用校验和相对刚性编译，不复制一套求解器，也不能只在 UI 设置不同标题。

进入机构仍忽略产品约束，包括产品固联；不会自动继承产品组。接合定义和转换得到的产品固联在创建后独立。

## 产品固联组的完整操作设计

本节补齐普通装配“固联组”的体验。现有多成员、嵌套／重叠、分阶段求解、抑制和历史合同继续以[当前装配约束](../current/assembly-constraints.md)为准，当前基础范围不另定义一个二体固联命令替代它。

### 创建与编辑

- 有预选：点击命令后将几何元素投影为当前 owning Product 的直接 Instance；两个及以上合法成员直接进入可确认草稿，一个成员则等待继续拾取。
- 无预选：立即进入成员选择拥有者，三维悬停与点击高亮整个 Instance；结构树可选择组件或已有固联组。所有输入共用 selectionInput，不另接鼠标监听器。
- 对话框提供组名称、已选成员列表和移除操作；列表显示零件／组名与状态，不使用组件多选下拉作为主要输入。打开后持续接受三维及树选择，直到确定或取消。
- 重复点击已选成员按明确的列表切换规则移除；点击已有组图标／树节点添加其 GroupID，展开后的几何点击仍选择具体 Instance。通过对象来源区分，不能从显示名猜组。
- 修改至少保留两个合法叶成员，拒绝自引用、环和非法重复展开。现有嵌套／重叠策略由同一领域校验执行，不在 UI 展开后另存一份不同成员集合。
- 输入变化撤销旧确认资格，预览采用生产组分阶段求解；确定一次提交定义及合格位姿，取消、Esc、关闭恢复入口，失败保留草稿。

构件多个实例始终用稳定 InstancePath/Instance 身份区分，两个引用同一 Part 的实例可以固联。嵌套刚性 Product 内拾取解析为当前可编辑 owning Product 的直接 Instance；当前基础范围不展开为柔性装配。

### 视图区和结构树

每个公开固联组只有一个正式约束标记，使用普通约束的图标、颜色、激活状态、可见性及稳定 ConstraintID。标记可以根据成员显示范围放置，但显示用包围盒不得参与捕获和求解。

点击标记或主树节点高亮全部有效成员，嵌套组递归解析并去重；点击单个成员引用只高亮该成员。预选与选中、显隐、重命名、抑制／激活、删除、刷新和 Undo/Redo 复用同一投影身份。

~~~text
Product
└─ 约束
   └─ 固联组.1
      ├─ Part.1（成员引用）
      ├─ Part.2（成员引用）
      └─ 固联组.2（组引用）
~~~

成员引用不是新 Instance，不提供删除真实零件的普通 Delete。成员管理通过所属组编辑或明确“移除成员”；删除组只解除组关系，保留所有组件和独立内部约束。Inspector 只读显示成员、展开范围、捕获及求值状态，编辑仍走正式命令。

普通受约束移动一个成员时全组保持捕获关系，共同参与求解；手柄 pointerup 后保留。不增加“自由移动后自动解除固联”的隐式模式。

## 共用支持、预览与结构树

JointDefinitionSpec 是薄描述表：接合 kind、必需支持角色、可创建坐标、默认参数、真实约束角色和闭合检查策略。用于组织已有选择／表单／编译流程，不能成为另一套 ConstraintRegistry 或参数模型。

支持角色扩展为轴、平面、点和 Instance；端点支持按类型可选，不能要求所有接合都有 Axis/Plane/Second.Frame 的旋转式输入。主 UI 使用机械名称，不向用户暴露 descriptor、solver profile、policy digest 或 primitive 名称。

拾取三步保持统一：按 owning Instance 和角色做粗筛选 → 服务端精确支持检查及正式派生 → 持久选择绑定。第一／第二端必须不同 Instance；同端多个支持必须来自同一端。删除或替换某端 Instance 时一并清理依赖的几何支持及捕获读数基准。

不完整预览只用于几何角色反馈，不能创建 Driver、生成完整 Joint 或获得保存资格。数据达到该类型的完整条件后，定义预览、确认、会话、路径和转换必须编译相同的真实关系。

~~~text
机械装置.1
├─ 接合
│  ├─ 棱形.1 → 重合.1 / 角度.1
│  ├─ 圆柱.1 → 重合.2
│  ├─ 平面.1 → 重合.3（或偏移.1）
│  ├─ 刚性.1 → 固联组.1
│  └─ 球面.1 → 重合.4
├─ 命令
│  ├─ 命令.1（棱形.1，长度）
│  ├─ 命令.2（圆柱.1，角度）
│  └─ 命令.3（圆柱.1，长度）
└─ 固定零件
~~~

上面编号只是示例，不按数组位置生成。接合子关系仍编辑 owning Joint；刚性子组可有只读成员引用，不能形成独立编辑相对捕获的入口。Product 固联组与机构子组的 OwnerDomain、MechanismID、JointID 及 ConstraintID 必须明确，不能因同属一个文档就混用编辑命令。模拟中的引用投影仍指向同一源身份。

## 稳定标量坐标、限位与零位

### 唯一数据模型

下表为统一合同；当前 API 与字段约束见[模型](../../../services/internal/workspace/kinematics_model.go)和[当前机构合同](../current/kinematics-dmu.md)，已有旋转路径也使用该模型。

| 对象 | 拥有的信息 |
|---|---|
| JointCoordinate | 稳定 CoordinateID、所属 Joint、语义角色、角度／长度维度、方向、不可变物理 Zero、共享端点局部捕获、Lower/Upper |
| MotionDriver | 稳定 DriverID、MechanismID、JointID、CoordinateID、Reference Quantity、ReferenceDigest |
| Mechanism 继续状态 | 按 CoordinateID 的规范坐标值，以及角约束的连续分支；不是 JointID 对应一个 float |
| 活动驱动集合 | 会话选择的 DriverID 集合、资格和摘要，不改变持久物理 Joint 定义 |
| Simulation | 稳定源机构、活动 DriverID 集合、各命令冻结 Reference、完整初始构型／继续状态、Keyframes |
| Keyframe | 稳定 ID、时间、整个活动集合的 values[DriverID]、可选视点 |
| 合格 Frame | 全部成员与冻结环境位姿、coordinates[CoordinateID]、commandValues[DriverID]、分支和见证 |

坐标角色至少为 AXIAL_TRANSLATION、AXIAL_ROTATION，唯一性为所属 Joint 加角色；CoordinateID 创建一次持久保存。相同 DriverID 不可改绑另一个 Joint 或 Coordinate。名称、行号、值的单位和 enum 在数组中的次序不充当身份。平面、球面和刚性不为满足数据格式伪造标量坐标。

端点局部 Frame 和 CapturedX 由 Joint 保存一份，各坐标引用其所需部分，不为圆柱的两个坐标复制两套可分别改变的 Frame。当前基础范围不提供原 Joint 的类型切换：不同类型使用各自创建命令，编辑只修改该类型的参数／支持。删除后新建分配新身份；被记录引用时先显式处理记录，不能保留旧 ID 而把角度换成长度。

Angular 规范计算为 rad，Linear 为 mm；显示按文档单位转换。Length Quantity 的 m/mm 转换与 Angle 的 deg/rad 转换分别执行，不允许任何维度混用。长度不进行 2π 取模或角展开；轴角保存多圈意图。

### 限位和置零

对每个可定义的标量坐标，都使用 u=q−q_ref 与显示范围 [lower−q_ref, upper−q_ref]。驱动时两端有限且 lower<upper，取消驱动后保留原限位。默认显示角范围 ±360°、长度范围 ±100 mm，缺失端才补默认值，已有端不覆盖。

命令节点仍只读显示所属接合、坐标类别、当前值，提供“置零”与确定／取消。置零只改变该命令读数原点，不能改变局部几何 Frame、另一坐标方向、物理限位、任何成员矩阵或已有运动路径。

Simulation 冻结每个活动命令的旧 Reference。打开时按各自维度换算私有草稿：

~~~text
u_new[d] = reference_old[d] + u_old[d] − reference_current[d]
~~~

保留关键帧 ID、精确时间和物理目标。新读数在确认前不回写原记录；取消恢复原记录。单纯置零不使物理录制基准失效，改变坐标方向／支持／捕获则要求明确重新验证，不把角度值直接复制为长度值。

## 机构自由度与活动驱动集合

设全部物理硬关系为 F(X)=0，入口合格构型的物理切空间为 N，选中标量坐标集合为 q_A。可驱动资格基于 Dq_A·N 的独立性、机构 gauge 及驱动后的实际剩余自由度；不能以 commandCount 直接代替 rank。

当前基础范围采用完整驱动的确定性试动／录制：活动集合的独立覆盖应等于可动机构的物理自由度，加入当前坐标值的硬方程后剩余自由度为零。非成员冻结关系不算用户 Ground；数值消除 gauge 也不算用户固定件。多个活动连通分量都要有合格的固定基准及完整驱动覆盖。

可通过现有求解器的物理与驱动探测求解取得 rank/DOF 证据；如现有 Worker 输出不足以区分覆盖与冗余，应正式扩展资格报告。不要在浏览器近似 Jacobian，也不要增加临时世界 Fix 来使探测成功。

| 情况 | 行为 |
|---|---|
| 固定端＋单棱形，长度命令 | 一个有效长度驱动即可试动／录制 |
| 固定端＋圆柱，两项命令独立 | 两项同时作为活动集合；一个目标请求整体求解 |
| 圆柱的一项运动已被其他关系消除 | 只启用剩余的独立命令；已被消除的候选命令不参与 |
| 单圆柱只勾选一个命令，剩余自由度为二 | 可保存、普通移动；命令试动提示“请补充驱动”，不隐藏锁另一项 |
| 平面／球面是被动连接，其他驱动覆盖整体自由度 | 正常参与全部试动、录制、路径和转换 |
| 平面／球面独立且无命令 | 可保存、受约束移动；没有命令录制资格 |
| 选中两个描述同一自由度的命令 | 拒绝该活动集合，保留全部候选命令和完整检查点 |
| 闭环奇异导致坐标失去参数化能力 | 分类拒绝当前目标／集合，保持最后合格构型，不换支 |
| 仅 Ground／Rigid、物理自由度为零 | 定义与转换可用；不伪造运动模拟 |

驱动接合仍不要求直接连 Ground。限位在目标资格检查中生效，不靠“恰好处在限位端点”把欠驱动伪装为完整驱动。多候选命令不会在定义求解中同时施加角／长度锁。

## 试动对话框与会话所有权

使用既有主拥有者及 actor/document/Revision/generation/sequence 屏障。Begin 验证物理入口，返回完整合格帧、候选读数和活动集合资格；未建立完整集合时可显示选择及资格，不开放数值试动或录制。该准备状态不创建模拟业务节点。

界面展示“使用的命令”及命令行：接合／参数名、使用复选框、当前值、单位、上下限和游标。活动行可输入，其他候选值作为结果读数回算。单坐标只有一行，不引入额外步骤或一串求解说明。

优先恢复同上下文最后成功的集合；结构树明确选择可用于预选。若只有唯一合格集合可直接采用；有多个可替代集合或预选不足时交给用户选择，不能任意挑选第一个 Joint 或按数量自动判定独立。

试动中更换活动集合在当前合格构型按实际坐标探测，成功才整体交接，模型位置不变。录制建立集合并自动记录 t=0 后，集合固定；当前基础范围不支持段内／跨段换驱动基，改变集合应重新开始录制。

数值更新发送完整目标向量。用户改一行时，其余活动坐标保持界面明确显示的目标值；此保持来自选中的活动命令，不是隐藏角锁。任一分量求解或限位失败，全部矩阵、读数、时间和记录资格一起恢复，不能先接受角度再拒绝长度。

空间操纵请求与数值目标互斥。DragTarget 仍作为满足物理关系后的运动偏好，不硬锁旧活动值；成功后从同一构型回算所有命令读数，再获得录制资格。播放中请求操纵须先在精确逻辑时间暂停／求解，再按该合格构型附着手柄；不能从近似显示矩阵直接形成保存候选。

状态边界为准备、资格待补充、就绪、求解、准备确认、提交、关闭。可恢复目标拒绝回到就绪；网络／CAS／上下文失效按既有合同处理。播放时钟、求解忙态和正式提交资格分开维护，避免把一次播放／拖动转成整个工具栏永久置灰。

## 向量录制、有限路径与播放

关键帧包含活动驱动集合的每一个值，不能缺项、出现未知 DriverID 或只存“最后操作的一行”。自动插入、插入、修改、删除、动画视点和逻辑时间继续复用现有录制流程。一次修改保留 Keyframe ID；主确定一次保存完整记录与当前合格位置，一次 Undo/Redo 恢复。

两个坐标的例子如下，显示单位仅为便于理解：

| 时间 s | 圆柱角度 ° | 圆柱长度 mm |
|---|---|---|
| 0 | 0 | 0 |
| 1 | 90 | 20 |
| 2 | 180 | 20 |
| 3 | 0 | 0 |

同段按共同时间参数对完整向量插值；前一段同时旋转与伸长，第二段保持长度，最后一段整体返回。不为角度和长度各建一份互不相干的轨迹或分别应用 Instance 矩阵。

连续求解在所有活动坐标的规范变化和完整刚体位姿变化上设置预算／子步，角度与长度使用各自尺度，混合步由最严格分量决定。长度步策略须绑定冻结的模型尺度、solver profile 与 policy，不能复用固定弧度阈值，也不能从浏览器包围盒猜尺度。失败回滚整个私有继续状态，包括所有角分支和数值种子。

每个目标验证全部物理关系、Ground、活动坐标、已启用限位、完整有限位姿和分支；关键帧本身通过不等于中间路径通过。保留失败时间、最后合格前缀和用户原记录。非活动但具有限位的棱形／圆柱／旋转坐标同样受检查。

播放仍使用合格有限缓存与显示插值，时间两位小数而逻辑时间不舍入。起点、终点、暂停、时间拖动、确定和产品转换须求解该精确时间的完整目标向量。相机独立，结果仍按稳定 Job ID 挂在自己的模拟下。零位重置不能改写旧缓存的物理解释。

View 的 Product 与 resolvedInstances 必须来自同一冻结文档投影；数值 nominal 和历史非成员环境只编入数值输入。回放只覆盖 Instance 根节点，不能改写其内部 Body 局部变换。验收同时观测根矩阵、实体世界矩阵和刚性组内部相对矩阵。

## 转换为独立产品约束

仍从既有工具栏入口生成可审阅计划，并使用一次正式事务提交。默认仅转换物理关系，不将候选命令、限位或时间轨迹复制为装配约束。

| 接合 | 默认转换 |
|---|---|
| 棱形 | 原轴重合＋绕参考轴的定位角 |
| 圆柱 | 原轴重合 |
| 平面 | 原平面重合或指定偏移 |
| 刚性 | 新的两成员产品固联组及独立捕获身份 |
| 球面 | 原点重合，保留球心等正式派生来源 |
| Ground／旋转 | 沿用既有固定／轴重合＋定位偏移 |

可选静态锁从“锁定角度”推广为显式选择可用的坐标。棱形可锁长度，圆柱可分别锁角度／长度；不勾选的运动仍保留。平面与球面当前基础范围没有定义相应命令坐标，不提供含义不明的“锁定欧拉角”。

角锁复用正式参考轴与 CapturedDirection。长度锁必须采用接合坐标原点的 point–plane 有向 Offset，一端是 B 的坐标点，另一端是 A 的坐标平面；不能把同轴线线距离写成行程。其符号与坐标方向、选择顺序一致。

为长度锁定义明确的 captured body-local Frame 支持：绑定稳定 InstancePath／源支持、冻结局部 Frame、单位和策略；作为正式派生支持解析为坐标点／法向平面。可复用既有 Frame 子元素求值，若当前公共引用不能携带该捕获则在正式协议中补齐。生成的产品支持和捕获归新产品约束拥有，不能留下对 Mechanism/Joint 临时 Frame 的运行依赖，也不自动改写被引用 Part 或新增跨文档 Publication。

AssemblyGeometryRef 的正式 CapturedFrame 支持携带 capture policy、源稳定引用和有限的右手 body-local Frame，使用新的产品约束／支持身份，经过与普通引用相同的来源、单位、权限和几何连接检查。不能仅存一个匿名 world 点或把临时 Worker geometry ID 当作持久引用。实现合同见[约束拥有的局部捕获支持](../current/assembly-constraints.md#约束拥有的局部捕获支持)。

转换刚性关系时先按现有产品组内部／外部求解规则检查所选构型：若组内产品约束要求不同相对位姿，计划报告冲突，不以重新捕获掩盖差异。复制成功后产品组按产品自己的更新合同运行，后续产品编辑不反馈机构。

映射以 JointID＋稳定 RelationRole 定位，不假设约束条数为二或统一角色为 axis/axial-location。新组成员引用只指向目标产品自己的实例／组。关系、捕获和参数一致才可 REUSE；差异为 CONFLICT。删除目标后重新分配身份，取消不改模型，成功一次保存完整位置、关系、参数、计数器与映射。

## 数值实现与职责分配

~~~mermaid
flowchart LR
    Pick["三维 / 树选择"] --> Support["既有精确支持与持久引用"]
    Support --> Joint["Joint 定义 / 坐标 / 真实约束"]
    Joint --> Compile["既有 FreezeAssemblyInput 与约束编译"]
    Vector["完整驱动目标向量 / 空间偏好"] --> Compile
    Compile --> Worker["现有 Geometry Worker / Assembly Solver"]
    Worker --> Witness["按类型闭合 / 限位 / 分支 / 完整帧"]
    Witness --> Owner["唯一会话检查点"]
    Owner --> Record["向量关键帧 / 有限路径"]
    Owner --> Commit["正式确认 / CAS / Undo"]
~~~

物理编译只保留 Joint 的实际关系和冻结环境，活动坐标编译单独返回一组候选方程。棱形／圆柱长度目标编译为坐标点到坐标平面的 signed Offset；转角使用既有 projected directed Angle；球面为 Point–Point Coincidence；平面为 Plane–Plane Coincidence/Offset；刚性消费冻结组的相对 RIGID 方程。预计无需新的数值约束原语，但支持矩阵、解析 Jacobian、rank 与实际 Worker 必须逐项证明。

按类型的闭合检查分别为：棱形的同轴及定位角；圆柱的同轴；平面的法向及有向平面距离；球面的点位置；刚性的完整相对 SE(3)；Ground 的空间基准。禁止沿用现有“所有接合原点相同、Z 轴相同”的旋转式后置检查。

## 实施依赖与退出条件

实施顺序只在[统一路线](../../../plans/README.md)维护。实现任务须在扩展接合界面前打通稳定坐标、活动集合与向量记录合同；固联体验和刚性捕获复用须在刚性 Joint 声称完成前闭环。可以分阶段提交，但最终必须同时满足下表，不能把“可保存类型”作为模拟已经支持的证据。

| 验收组 | 必须实际证明 |
|---|---|
| 棱形 | 两线两面真实拾取；任意装配朝向、轴方向、非零定位角；长度正负和 m/mm 单位；仅沿轴移动，旋转被锁，物理剩余 1 DOF |
| 圆柱 | 只有两轴；物理剩余 2 DOF；角度／长度分别生成稳定命令；双驱同步、单驱欠驱提示、其他关系消除一项后单驱有效 |
| 平面 | 同向／相对、零和非零偏移；面内平移及法向转动允许，离面和倾斜拒绝；不能误变成点／Frame 重合 |
| 球面 | 两稳定点和实际球面派生球心；点不分离，三个方向转动保持；伪球面拒绝，顶点／Publication 重建后正确解析 |
| 刚性 | 两几何预选解析 Instance；未接地对整体仍可动；移动／试动不重捕获；新冲突不改变旧相对基准；固定一成员后全对固定 |
