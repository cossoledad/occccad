# 简化百岁山瓶身

本例只建立**圆柱瓶身与四条 S 形凹槽**。主链为“圆柱拉伸 → 单槽扫掠切除 → 圆周阵列”，不再使用整体扭转的多截面放样，不包含瓶颈、瓶盖、螺纹或薄壁。功能与选择合同见[线框与曲面](wireframe-surfaces.md)。

用户提供的[参考文章](https://zhuanlan.zhihu.com/p/410228249)在本次访问中返回 HTTP 403，未能核对原文步骤；造型依据用户明确描述的圆柱与四条类似 tan 函数的凹槽。以下为示例尺寸，不是实物测绘。

## 尺寸与步骤

| 项目 | 示例值 |
|---|---:|
| 圆柱半径 / 高度 | 30 / 160 mm |
| 圆形切削截面半径 | 4 mm |
| 路径控制点所在半径 | 32 mm |
| 槽的名义径向深度 | 约 2 mm |
| 槽数量 / 周向间隔 | 4 / 90° |

1. 在 XY 草图中建立圆，圆心与原点重合、半径约束为 30 mm；拉伸 160 mm，形成圆柱。
2. 在圆柱外侧准备一条 S 形空间样条。下、上端分别延出瓶身；中段转向，两端较直。使用 11 个关联参考点、三次控制点样条。首两个、末两个控制点分别具有相同 XY，使端部切线沿 Z。
3. 建立经过路径起点、平行于 XY 的关联平面，在该面建立半径 4 mm 的圆形草图；圆心位于草图原点。该支撑随路径起点参考点移动。
4. 选择圆截面和空间样条，以修正标架扫掠并**切除材料**，形成第一条圆底凹槽。
5. 选择这项扫掠切削工具，绕圆柱 Z 轴进行完整圆周阵列，数量 4。原槽加三个复制成员形成四条凹槽。
6. 隐藏两张输入草图及路径/参考点集合，保留依赖。最终仅显示一个瓶身 Body。

## S 形路径的准备

控制点轴向位置为 `−8, −1, 40, 60, 72, 80, 88, 100, 120, 161, 168 mm`。令 `u = clamp(z, 0, 160)`，使用下面的配方准备参考点坐标：

```text
theta = 0.55 * atan((u - 80) / 14) / atan(80 / 14)
x = 32 * cos(theta)
y = 32 * sin(theta)
```

在圆柱展开视图中，该走向与有限区间的 tan 曲线对应；当前造型由样条近似，槽深随样条和切削截面的空间姿态略有变化。这里没有新增公式曲线命令，也不承诺恒深槽。

## 编辑与检查

- 圆柱高度在拉伸特征中修改；圆柱与切削截面的半径在各自草图尺寸中修改。槽的走向通过路径参考点和样条控制点调整，四条槽共用同一切削工具。
- 修改圆周阵列数量可检验复制及材料切除；撤销后应恢复四条槽及原精确结果。结构树总计六项 Feature：两张草图、圆柱拉伸、空间样条、扫掠切除和圆周阵列。
- 检查最终一个有效 Solid、完整 Naming、种子及三个不同阵列成员，并分别查看正视、侧视、等轴测；STEP/BREP 导出只包含瓶身。
- 体积加减仅作为数值对照，不能代替有效性和阵列身份检查。本例不核验容量、真实壁厚或制造尺寸；执行记录、截图与交换文件归当次 build 制品，不将开发文档 ID 固定为产品入口。
