# 简化百岁山水瓶示例

本例使用当前独立 Part 的正式参考点、曲线、曲面和 Body 命令建立可编辑历史，外形参考[百岁山官网的 570 mL 产品图片](https://www.ganten.com.cn/uploads/20210324/eae574fad9cb9675ea2adf0772ade7dc.png)。下列尺寸为示例设计值，未测绘实物，也未核验容积、材料或制造要求。功能边界见[线框与曲面](wireframe-surfaces.md)及[当前实现](../architecture/current/wireframe-surfaces.md)。

## 瓶身

每个截面选择 16 个关联参考点，以闭合插值样条连接。点按相同顺序建立，截面按 Z 排列；四瓣起伏和截面转角近似表达瓶身筋线。修改参考点会沿曲线、放样和加厚的依赖传播。

截面点按 `θ = 2πi/16`、`ρ = r + a·cos(4θ)`、`(x,y) = ρ·(cos(θ+φ), sin(θ+φ))` 准备；这是本例生成参考点坐标的配方，当前产品没有新增公式曲线命令。

1. 按顺序选择 11 个截面，建立平滑“曲面放样”。
2. 选择底部截面做 G0 填充，再将侧壁与底面缝合；瓶口保持开放。
3. 对开放壳加厚 `−0.5 mm`，生成独立薄壁瓶身 Body。
4. 将截面、点及曲面放入构造集合并隐藏，保留依赖；瓶身设浅蓝半透明外观。

## 瓶盖

在 Z=210.5 mm 和 228.5 mm 建立半径 14.8 mm 的圆。圆心采用参考点，支撑采用过点平行于 XY 的关联平面。两圆放样侧壁、填充上圆并缝合，底部保持开放；加厚 `−0.8 mm` 形成另一个 Body，设置白色外观。隐藏瓶盖可检查瓶口和内壁，完成后恢复显示。

## 本例覆盖与后续需求

本例覆盖非圆闭合样条、多个有序截面、扭转外形、收肩/瓶颈、G0 填充、开放壳缝合、薄壁实体、多 Body 外观与 STEP/BREP 导出。官网图片只作外形参考；执行记录及模型文件归当次 build 制品，不将某个开发文档 ID 固定为产品入口。

本例省略商标文字、瓶口螺纹、防盗环、瓶盖细齿和真实瓶底脚。细齿、环及局部材料编辑可继续使用现有实体工具；精确螺旋线/螺纹、文字转曲线与包覆、带导向/耦合的曲面构造尚无专用命令。批量关联点/截面模板与变换法则可显著减少此类瓶身截面的逐点准备，这是操作效率方面的后续需求。透明显示沿用现有透明排序，不是物理折射玻璃。
