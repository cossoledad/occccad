# 使用线框与曲面

在独立 Part 中，从建模工具栏或工具搜索进入“线框与曲面”；“零件设计”返回 Part Design。切换工作台不会提交模型。当前功能与算法边界见[当前架构](../architecture/current/wireframe-surfaces.md)。

## 从曲线建立实体

1. 创建直线、圆弧或样条，直接填写坐标，或用点字段拾取已有参考点/几何点。样条可切换插值点与控制点，按需增删点、设置次数和权重。
2. 打开“拉伸曲面”，在视图区拾取曲线；选择整个草图时固定当前曲线成员，选择树中特征结果时引用整个结果。设置方向、长度并检查预览，再确认。
3. 打开“加厚”，拾取曲面，设置有符号厚度和新实体/添加/切除。添加或切除时从视区或树拾取目标 Body。确认后的实体可继续使用原圆角等工具。
4. 双击树中特征修改定义或表达式。上游变更传播到曲面及实体；撤销/重做、重新打开沿用同一模型历史。

线框/曲面工作台创建的草图与几何特征放入几何图形集；已有实体草图可以直接作为输入。集合控制显示，隐藏源集合不会隐式删除依赖。修改对象名使用树中的统一改名操作。

## 关联和编辑

提取、边界、组合、投影、交线和偏移均通过字段激活拾取；替换/移除输入使用字段操作。有限面遵守修剪边界，基准面为无限支撑。偏移需另拾取基准面；分割、修剪及曲线上点使用归一化弧长比例，延伸使用物理长度。G1 连接先检查两条曲线的端点方向，必要时反向。

原“扫掠”的路径曲线字段可直接拾取空间曲线。正式三维路径要求连通且 G1，截面在起点且与切线垂直；选定后隐藏只适用于草图路径的控件。

输入不足时确认不可用；计算失败使用全局提示，修正参数或替换输入后再次预览。取消不产生 Revision。不要用输入显示名或当前网格编号手工修复关联。
