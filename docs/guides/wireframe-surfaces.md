# 使用线框与曲面

在独立 Part 中，选择与“实体”并列的“线框与曲面”标签。切换标签不会提交模型。当前功能与算法边界见[当前架构](../architecture/current/wireframe-surfaces.md)。

## 从曲线建立实体

1. 先准备参考点、方向线和支撑面。打开直线后选择起点、终点；圆/圆弧选择圆心和支撑平面，填写半径/角度；样条从空点列开始，在视区或树中逐点选择。命令前已选的兼容对象会按角色带入；无预选时字段为空。样条点列支持插前/插后、更换、移除，控制点方式可调整次数和权重。
2. 打开“拉伸曲面”，在视图区拾取曲线；选择整个草图时固定当前曲线成员，选择树中特征结果时引用整个结果。再选择方向线、参考轴或平面法向，调整长度、必要时反向，检查预览后确认。修改上游方向线会联动改变曲面，无需重新编辑拉伸。
3. 打开“加厚”，拾取曲面，设置有符号厚度和新实体/添加/切除。添加或切除时从视区或树拾取目标 Body。确认后的实体可继续使用原圆角等工具。
4. 双击树中特征修改定义或表达式。上游变更传播到曲面及实体；撤销/重做、重新打开沿用同一模型历史。

“线框与曲面”标签创建的草图与几何特征放入几何图形集；已有实体草图可以直接作为输入。可在树的右键菜单中单独显示/隐藏几何结果，也可用集合统一控制；隐藏源几何不会删除依赖。修改对象名使用树中的统一改名操作。集合可在“对象”菜单中设为工作集合；“移入集合…”组织对象，“解散集合”保留内容并移到指定集合。属性中的图形页可设置颜色、线型或点符号，未覆盖的字段继承父集合。

## 构造和编辑工程曲面

| 命令 | 选取顺序与操作 |
|---|---|
| 旋转曲面 | 轮廓 → 关联轴线 → 角度；修改上游轴线可联动更新 |
| 曲面扫掠 | 截面 → Spine；截面先布置在起点法平面，可拾取导向，选择姿态或贴合边界，检查预览 |
| 曲面放样 | 依次拾取截面，反向/重排；闭合截面可选闭合点，“添加对应”后逐截面拾取同组点。选择 Spine 时补齐站位点 |
| 填充曲面 | 选取闭合边界；默认 G0，四条有序单边可逐边选择支撑与 G1/受限 G2 |
| 边界曲面 | 依次选四条首尾相连的边界，必要时反向；逐边设置连续性、支撑及张力 |
| 桥接曲面 | 两条同向边界；分别选择 G0/G1/G2，非 G0 时拾取支撑并调整张力/反向 |
| 曲率分析 | 拾取曲线、面片或独立结果，可切换曲线/曲面过滤，选择采样密度；曲面切换主曲率/均值/高斯曲率，曲线调整梳齿比例；曲面还可显示自由边、0.01 mm 范围内的间隙候选及法向。间隙列表可定位，未完成时缩小范围。完成后清除显示，不保存 Revision |
| 裁剪曲面 | 源曲面 → 切割曲面/平面或面上曲线 → 保留点；保留点应是上游参考点、草图点或曲线上点，位于需要保留的面内 |
| 互裁曲面 | 两张曲面 → 第一保留点 → 第二保留点；两侧均保留指定区域 |
| 延长曲面 | 源曲面 → 该面的自由边界 → 长度；当前支持单个矩形参数域曲面的等参数边 |
| 连接曲面 | 依次选取相连的面片，作为关联面集；需要共享边界的壳时再缝合 |
| 缝合曲面 | 选取相邻面片或面集，按给定容差建立壳体；断开或非流形输入不能确认 |
| 偏移曲面 | 曲面 → 有符号距离；调整距离后检查自交和边界 |
| 封闭曲面 | 已缝合的闭合壳 → 实体操作；有开口时先填充并缝合，命令不自动加盖 |

容差是工程参数，可使用表达式；它不会替代缺失的连接或让失败子面被静默删除。新建工程容差默认 0.01 mm，已有显式容差保持原值。几何输入来自视区、树或合法预选。

Spine/导向和高阶支撑的首版适用范围见[当前接纳合同](../architecture/current/wireframe-surfaces.md#形状控制与连续性接纳)。姿态模式不保证整条导向成为边界；贴合边界模式要求直线 spine、从 spine 指向导向点的直线截面和单调前进的多项式导向。G1/G2 支撑请选择原面自己的等参数边，或单段多项式边界的基准平面；相邻支撑角点不兼容时需调整几何/连续性，不能放大容差掩盖。曲率数值来自精确几何，但颜色、梳齿及显示范围均为采样观察。

典型闭环：有序闭合截面放样侧壁 → 分别填充两端 → 缝合侧壁与端面 → 封闭为实体 → 继续使用实体圆角等工具。修改上游截面或参考点后，下游沿同一历史重算。

## 显示和交换

独立曲线以紫色显示，与金色选中和青色悬停区分，曲面为蓝灰色，参考点及独立工程点为带描边的白色叉号；草图与实体顶点保持各自样式。缩略图也包含这些几何及集合显隐。树上悬停/选中独立特征会高亮对应结果；属性分别给出具体命令和几何类型。开放面具有双面光照和场景阴影。

使用原导入/导出入口交换 STEP 或 BREP。导出包含有效 Body 与可见几何结果；可先隐藏不需要交换的源曲线、曲面或集合。开放文件导入为几何图形集结果，可继续提取、偏移、缝合或封闭；混合输入完整保留为一个集合结果，当前不自动拆分材料 Body。交换不传递本软件的完整参数历史。

## 关联和编辑

提取、边界、组合、投影、交线和偏移均通过字段激活拾取；替换/移除输入使用字段操作。有限面遵守修剪边界，基准面为无限支撑。偏移需另拾取基准面或平面面片；平移选择方向和距离，旋转选择轴和角度，镜像选择平面。分割、修剪及曲线上点使用归一化弧长比例，延伸使用物理长度。G1 连接先检查两条曲线的端点方向，必要时反向。

原“扫掠”的路径曲线字段可直接拾取空间曲线。正式三维路径要求连通且 G1，截面在起点且与切线垂直；选定后隐藏只适用于草图路径的控件。

输入不足时确认不可用；计算失败使用全局提示，修正参数或替换输入后再次预览。取消不产生 Revision。不要用输入显示名或当前网格编号手工修复关联。

## 删除与修复

树中删除 Body、集合或任意位置 Feature 时，先检查删除范围、保留并更新项及接口影响。默认保留下游定义，可选择同时删除依赖特征，或清理独占的草图与参考几何；仍被其他对象或接口共享的输入会保留。取消不改变文档。

输入删除后，树标明失败/阻塞；双击消费者，从带缺失标识的字段重选合法上游输入，预览通过后确认。撤销和重做包括删除与修复两个独立历史动作。旧成功显示只供导航，不能作为当前可用的精确输入。详细语义见[Part 对象生命周期](../architecture/current/part-object-lifecycle.md)。
