# 使用线框与曲面

在独立 Part 中，选择与“实体”并列的“线框与曲面”标签。切换标签不会提交模型。当前功能与算法边界见[当前架构](../architecture/current/wireframe-surfaces.md)。

## 从曲线建立实体

1. 先准备参考点、方向线和支撑面。打开直线后选择起点、终点；圆/圆弧选择圆心和支撑平面，填写半径/角度；样条从空点列开始，在视区或树中逐点选择。命令前的选择不会自动带入。样条点列支持插前/插后、更换、移除，控制点方式可调整次数和权重。
2. 打开“拉伸曲面”，在视图区拾取曲线；选择整个草图时固定当前曲线成员，选择树中特征结果时引用整个结果。再选择方向线、参考轴或平面法向，调整长度、必要时反向，检查预览后确认。修改上游方向线会联动改变曲面，无需重新编辑拉伸。
3. 打开“加厚”，拾取曲面，设置有符号厚度和新实体/添加/切除。添加或切除时从视区或树拾取目标 Body。确认后的实体可继续使用原圆角等工具。
4. 双击树中特征修改定义或表达式。上游变更传播到曲面及实体；撤销/重做、重新打开沿用同一模型历史。

“线框与曲面”标签创建的草图与几何特征放入几何图形集；已有实体草图可以直接作为输入。集合控制显示，隐藏源集合不会隐式删除依赖。修改对象名使用树中的统一改名操作。

## 关联和编辑

提取、边界、组合、投影、交线和偏移均通过字段激活拾取；替换/移除输入使用字段操作。有限面遵守修剪边界，基准面为无限支撑。偏移需另拾取基准面或平面面片；平移选择方向和距离，旋转选择轴和角度，镜像选择平面。分割、修剪及曲线上点使用归一化弧长比例，延伸使用物理长度。G1 连接先检查两条曲线的端点方向，必要时反向。

原“扫掠”的路径曲线字段可直接拾取空间曲线。正式三维路径要求连通且 G1，截面在起点且与切线垂直；选定后隐藏只适用于草图路径的控件。

输入不足时确认不可用；计算失败使用全局提示，修正参数或替换输入后再次预览。取消不产生 Revision。不要用输入显示名或当前网格编号手工修复关联。
