# 使用线框与曲面

在独立 Part 中，选择与“实体”并列的“线框与曲面”标签。切换标签不会提交模型。当前功能与算法边界见[当前架构](../architecture/current/wireframe-surfaces.md)。

## 从曲线建立实体

1. 先准备参考点、方向线和支撑面。打开直线后选择起点、终点；圆/圆弧选择圆心和支撑平面，填写半径/角度；样条从空点列开始，在视区或树中逐点选择。命令前的选择不会自动带入。样条点列支持插前/插后、更换、移除，控制点方式可调整次数和权重。
2. 打开“拉伸曲面”，在视图区拾取曲线；选择整个草图时固定当前曲线成员，选择树中特征结果时引用整个结果。再选择方向线、参考轴或平面法向，调整长度、必要时反向，检查预览后确认。修改上游方向线会联动改变曲面，无需重新编辑拉伸。
3. 打开“加厚”，拾取曲面，设置有符号厚度和新实体/添加/切除。添加或切除时从视区或树拾取目标 Body。确认后的实体可继续使用原圆角等工具。
4. 双击树中特征修改定义或表达式。上游变更传播到曲面及实体；撤销/重做、重新打开沿用同一模型历史。

“线框与曲面”标签创建的草图与几何特征放入几何图形集；已有实体草图可以直接作为输入。可在树的右键菜单中单独显示/隐藏几何结果，也可用集合统一控制；隐藏源几何不会删除依赖。修改对象名使用树中的统一改名操作。

## 构造和编辑工程曲面

| 命令 | 选取顺序与操作 |
|---|---|
| 曲面扫掠 | 截面 → 路径；截面先布置在路径起点法平面，选择截面姿态后预览 |
| 曲面放样 | 依次拾取截面；在列表中反向、上移/下移，按需要启用直纹 |
| 填充曲面 | 选取闭合边界的曲线或边，检查 G0 补面预览 |
| 裁剪曲面 | 源曲面 → 切割曲面/平面 → 保留点；保留点应是上游参考点、草图点或曲线上点，位于需要保留的面内 |
| 延长曲面 | 源曲面 → 该面的自由边界 → 长度；当前支持单个矩形参数域曲面的等参数边 |
| 连接曲面 | 依次选取相连的面片，作为关联面集；需要共享边界的壳时再缝合 |
| 缝合曲面 | 选取相邻面片或面集，按给定容差建立壳体；断开或非流形输入不能确认 |
| 偏移曲面 | 曲面 → 有符号距离；调整距离后检查自交和边界 |
| 封闭曲面 | 已缝合的闭合壳 → 实体操作；有开口时先填充并缝合，命令不自动加盖 |

容差是工程参数，可使用表达式；它不会替代缺失的连接或让失败子面被静默删除。几何输入始终从视区或树中选择，命令打开时保持为空。

典型闭环：有序闭合截面放样侧壁 → 分别填充两端 → 缝合侧壁与端面 → 封闭为实体 → 继续使用实体圆角等工具。修改上游截面或参考点后，下游沿同一历史重算。

## 显示和交换

独立曲线以紫色显示，与金色选中和青色悬停区分，曲面为蓝灰色，参考点及独立工程点为带描边的白色叉号；草图与实体顶点保持各自样式。缩略图也包含这些几何及集合显隐。树上悬停/选中独立特征会高亮对应结果；属性分别给出具体命令和几何类型。开放面具有双面光照和场景阴影。

使用原导入/导出入口交换 STEP 或 BREP。导出包含有效 Body 与可见几何结果；可先隐藏不需要交换的源曲线、曲面或集合。开放文件导入为几何图形集结果，可继续提取、偏移、缝合或封闭；混合输入完整保留为一个集合结果，当前不自动拆分材料 Body。交换不传递本软件的完整参数历史。

## 关联和编辑

提取、边界、组合、投影、交线和偏移均通过字段激活拾取；替换/移除输入使用字段操作。有限面遵守修剪边界，基准面为无限支撑。偏移需另拾取基准面或平面面片；平移选择方向和距离，旋转选择轴和角度，镜像选择平面。分割、修剪及曲线上点使用归一化弧长比例，延伸使用物理长度。G1 连接先检查两条曲线的端点方向，必要时反向。

原“扫掠”的路径曲线字段可直接拾取空间曲线。正式三维路径要求连通且 G1，截面在起点且与切线垂直；选定后隐藏只适用于草图路径的控件。

输入不足时确认不可用；计算失败使用全局提示，修正参数或替换输入后再次预览。取消不产生 Revision。不要用输入显示名或当前网格编号手工修复关联。
