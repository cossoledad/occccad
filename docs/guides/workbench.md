# 工作台 UI 规格与组件入口

保留浅色操作区、深色顶栏与视口。呈现层不改变命令步骤、单次/连续、选择来源、参数原文或事务语义。几何选中仍使用橙黄色，工具激活使用蓝色。

## 操作与源码入口

全局快捷键由 [command-shortcuts.ts](../../web/apps/cad/src/cad/command/command-shortcuts.ts)拥有，经 CommandRegistry 检查可用性：Ctrl/Meta+Z 撤销，Ctrl/Meta+Y 或 Shift+Z 重做，Ctrl/Meta+K 搜索，V 选择，F 适合窗口，1/2/3/4 等轴/前/顶/右视图，L/C/R 直线/圆/矩形，Shift+/ 帮助。输入框和 IME 不触发全局命令；工具内部按键归各工具状态机，导航按键见[导航说明](../../web/apps/cad/src/cad/navigation/README.md)。

命令目录投影从 `workbench-command-model.ts` 进入，命令注册从 `workbench-command-registration.ts` 进入；标签、临时会话、树/Inspector 的边界见[编辑上下文](../architecture/current/product-edit-context.md)，不需要整读主 orchestrator。

新增面板默认在视口右上内侧16px，大面板工作台水平居中且避开命令区；已有保存位置按实测尺寸夹取。所有普通表单使用原有 Antd/Quantity 输入，表达式不转为InputNumber。尺寸编辑保持值/表达式、名称、定位、参考、停用、删除；逻辑约束合法引用更换继续存在。

## 命令表单与拾取

`cad/overlay/command-form.tsx` 的 `CommandField` / `CommandFormItem`、`CommandGroup`、`CommandStatus` 统一字段、Ant Form 校验、分组与计算状态；`FeaturePickField` 是引用字段和列表条目的唯一基本外观。装配支撑、接合端点、特征修复及有序截面复用它，几何合法性与持久绑定仍由各命令负责。草图连续工具保留自己的阶段操作，字段沿用公共布局。

标签列88px且左对齐；紧凑数值112px、常用枚举160px，短控件、分段选择和操作靠右；名称、表达式和选择列表伸展并共用右边界。内部数值、名称及枚举按各自语义对齐。`content` 用于分段或组合动作，不能借 `expression` 宽度拉伸；`CommandVector` 的XYZ三列等分，分量标签14px，固定约束与基准共用，均受可用宽度限制。普通控件32px，引用行内动作24px、最小48px，底部确认/取消最小64px，按钮按内容排布。复选项和开关不拉伸；长名称省略但保留完整 tooltip；多项枚举允许换行。不以父容器拉伸或全局固定宽度替代字段规则。

同一命令只有一个拾取字段。单选成功结束该字段；无序多选点击增减，有序截面按加入顺序保存并提供换序。更换开始时保留原引用，只有合法新选择才替换；取消更换保留原值，移除／清空显式清除并结束拾取，必需输入缺失时不能确认。集合使用 `FeaturePickField.items`：一个数量摘要与限高160px的紧凑列表，超过5项提供名称／路径筛选；可收起，失效和正在更换的项自动展开并保持可见。每行只显示对象名称、必要状态及定位／更换／移除图标，不再重复“种子、种子1…”卡片。无序集合不显示序号；有序截面保留序号与换序，专属参数只在该行设置中展开。集合入口显示“增减”，单项入口显示“更换”。定位结束拾取并高亮原对象，不作为新输入。树与视图共用 `FeatureSelectionSession` 校验；异步绑定受字段、会话及模型版本约束，迟到结果不得写回或结束新字段。

Esc 依次交给菜单／IME、当前拾取、命令。普通工具取消与空闲Esc清空树／视图选择、hover和临时高亮；取消引用更换保留已接受输入。不在普通deactivate中清除预选择，不增加全局监听。Enter 排除 IME、重复按键、下拉候选和多行输入；普通输入在解析与状态更新后至多确认一次，非法数值中间串不能确认旧值。失焦只更新草稿／预览，不提交模型。确定仍依赖当前输入的有效候选，关闭清理临时引用与预览。重新预览、应用并继续等辅助操作归入 `CommandDialog` 底部；只读分析保留刷新／取消分析语义。

阵列共用一个入口，在面板内选择线性／圆周；镜像独立入口。种子只从树／视图拾取，实体特征可多选，列表逐项定位、更换、移除；同一集合限定同 Body、同添加／切除语义，最多32项。不要求先选择内部来源类型。方向、轴、中心点与镜像平面显示具体名称／路径，并提供定位、更换、移除；材料使用统一分段字段，反向位于最后。普通特征选取使用生成工具或合法新增材料范围，明确选择“实体阶段”才复制完整阶段；既有定义不被静默转换。

参数对话框固定创建区、搜索和列表表头，仅参数条目区域滚动，窄窗口及缩放时仍可操作顶部控件。

字段附近显示明确的本地校验原因，服务失败经公共错误映射；不把本地错误字符串交给文案白名单猜测。仅保留缺失输入、计算中、过期和实际失败，移除“点击添加选择”“自动预览”“预览成功可确认”等常驻教学。

## 工程信息表达

- 模型命令与分析使用 `CommandDialog` 的焦点、拖动、位置记忆、边界和 Esc；全局选项在主页和工作台复用同一可拖动容器、边界及位置恢复，合法设置每次修改即应用并保存；关闭不回退，非法中间输入不覆盖已接受值；文档导航保留其导航容器。视口拾取不被遮罩阻断。
- 操作失败统一进入右下角公共通知，包括进入／退出机构、异步更新及命令失败；禁止把错误 Alert 插在工具栏与工作台布局之间。字段校验保留在所属字段，持续工程状态留在所属面板；历史查看等模式提示不占用页面布局高度。
- 首屏先给对象名称、工程状态／数值和下一步动作。名称由对应文档、实例路径和稳定引用解析；重名实例补充路径或实例序号，缺失引用明确标为丢失，禁止用完整／截断 ID 兜底。
- 普通表格、选择提示、属性、通知、tooltip 不呈现 UUID、Revision ID、digest、原始枚举／异常、JSON、诊断复制和实现过程；版本任务保留名称、时间及更新状态。映射来自现有状态和错误证据，未知如实说明，不猜测错误原因。
- DEBUG工具栏的“开发信息”打开独立、可拖动非模态面板，集中当前对象、最近结果／失败、请求耗时、查询调试、助手调用及诊断下载。关闭时不加载开发查询，页签按需加载；不取消建模工具或占用拾取会话。属性／历史仅保留工程信息，所需工程查询不依赖开发面板。
- 机构打开／切换自动分析或复用当前版本结果；同一输入合并在途计算，取消、关闭和版本变化阻止迟到结果恢复。相对自由度与整体运动分开。选中运动零件联动直线平移箭头／真实轴线处的旋转弧箭头；固定、未知、构型不匹配不显示误导标记。
- 所有精确值、引用身份、权限、求值、预览确认、未知回执恢复、Undo/Redo 均保留原合同；展示名称和舍入值不得回写计算输入。

布尔的“全部／选择区域”表达动态全部结果与明确保留集合。结果区复用紧凑 `FeaturePickField`，保留／排除状态、定位和临时单独显示与视图区的整块体积拾取联动。候选显示独立于最终预览请求；更换目标／工具或版本变化使旧分析失效，旧引用逐项保留待修复。临时角色样式和隔离不写正式可见性，详细区域证明只进 DEBUG。

孔编辑器按当前孔型显示活动参数，锥段派生深度使用当前权威预览的 Quantity，不从格式化文案或旧预览推算。若孔自身有效而下游引用失效，显示孔阶段及首个实际待修复特征；该提示不表示最终 Body 已成功，确认仍经完整求值。

## 参考几何、树与文档导航

基准面／轴普通颜色、预览、hover和选中来自既有视觉主题；预览和正式对象共用构造几何与屏幕尺寸。标准平面和绝对XYZ轴取同一0.18–0.90范围，XYZ无箭头且留原点间隙。原点关闭深度检测、独立高层拾取并限制屏幕容差；隐藏、命令过滤和occurrence仍约束候选。

新对象创建时按所属作用域分配 `Type.N`（如Extrude.1、Sketch.1、Plane.1、Axis.1、Circle.1、Coincident.1），避开已有名称；自定义名不批量改写。草图实体／约束名称随定义和ChangeSet保存，树不再按数组顺序编号。预览仅在候选中取名，重试、撤销重做和重开沿正式身份与历史，不额外永久占号。参数别名和引用身份不由显示名替换。

树始终保留对象类型图标，工程状态使用右下角标和可访问说明，不追加状态文字。选中用选择底色、hover用悬停底色、键盘焦点用轮廓、编辑对象用既有编辑标记、工作Body用粗体下划线；隐藏淡化类型／名称，抑制名称斜体划线，角标仍可读。多选语义不变。右键按鼠标位置，键盘菜单按焦点行；递归菜单统一256px／32px行高、图标空槽、文字、快捷键和箭头，边缘自动避让，所属对象子菜单统一“对象”。

插入每次打开从实际目标Product所在文件夹开始，无文件夹从根目录开始，嵌套编辑使用目标文档上下文；用户导航不因查询刷新复位，保留全部文档及跨页选择。主页页大小贯通查询键、limit、offset和控件，切换页大小／筛选／目录回第一页，删除后夹取合法页码。

表达式沿既有解析、量纲与依赖机制，`len/2` 与 `len / 2` 等价；括号、单位、一元负号及科学计数法无需强制空格，保存原文，不用格式化显示改写输入。

草图入口沿 catalog 的 variants 分组：点包含创建交点，圆包含椭圆，直线/折线、圆弧、修剪/分割/延伸、变换各归同类；删除主要使用键盘及对象菜单。状态栏只显示当前角色、实际问题与恢复动作，不重复显示同一命令的整段教学提示。拾取及角度语义统一见[Part/Sketch](../architecture/current/part-sketch.md)。

## 定向验证与人工检查

公共交互入口：`workbench-visual`、`workbench-more-commands`、`sketch-inline-ui`、`sketch-input-session`、`sketch-linear-input`、`sketch-continuous-selection`、`sketch-direct-workflow`、`sketch-feedback`、`sketch-dimension-lifecycle`、`assembly-engineering-panel` 场景；执行 `pnpm typecheck` 与 `pnpm build`。测试通过不等于WebGL实机验收通过。

人工在1920×1080、1366×768、1024×768及125%/150%缩放检查：

1. Part/Sketcher/Assembly切换分类、逐页切换到末组；圆/圆弧/样条菜单靠左右边缘均可打开。主区单击/双击、主区后立即点击箭头、禁用/帮助模式保持原行为。菜单Esc只关闭菜单，Tooltip不挡点击。
2. 打开拉伸M、装配约束M、分析L、尺寸S；初始焦点为字段，Enter一次提交，IME不提交；拖动后重新打开保留位置，小窗口关闭入口可达。
3. 圆角R和尺寸内联输入在边缘稳定避让；输入表达式与非法中间串不丢草稿，失焦不提交。只读文字没有重复DOM副本；观察深背景、浅实体、选中、参考、错误、斜视与缩放。
4. 错误说明位于右下状态栏上方；正常通知没有技术详情或诊断复制入口。未知结果通知不自动消失，关闭通知后状态栏恢复动作仍在。正常完成/取消不新增成功或错误通知。
5. 沿既有矩形→四角R5→长度80/间距50→圆分割/修剪→构造弦镜像→拉伸流程检查，确认没有新增步骤。

运行截图和临时检查记录放在派生 `build/ui-unification/`，不加入长期架构历史。Mock/软件WebGL截图只能证明呈现与前端接线；真实服务、原生GPU及几何/历史闭环另行实机验收。

工具按钮宽88px，分体按钮宽112px（箭头24px）；命令区按可用宽度分页，上一页/下一页替换整页内容；整组优先，单组超宽时按双行列拆分。切页不改变工具状态，所有命令继续可搜索。组间分隔使用蓝灰色 `#8A9FBE`。

数值显示统一使用 `utils/display-number.ts`，最多两位小数，省略尾零；输入中的草稿、表达式原文和模型计算精度保留。普通数字输入使用 `cad/overlay/cad-number-input.tsx`；formatter 保持稳定身份，失焦或 Enter 对未修改的舍入显示不形成新数值意图；实际输入和原有 parser、范围校验继续生效。未修改的舍入显示不得写回参数或拉伸长度。
